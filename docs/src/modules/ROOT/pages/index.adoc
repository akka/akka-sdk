= Akka Documentation

Akka has one offering: the Akka Agentic AI Platform, which provides resilience and scalability for the agentic systems you build with it. Its four solutions are Akka SDK, Akka Specify, Akka Verify and Akka Optimize. See xref:ROOT:about-akka.adoc[About Akka].
