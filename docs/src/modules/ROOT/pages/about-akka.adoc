Akka has one offering: the *Akka Agentic AI Platform*, which guarantees the resilience and scalability of the agentic systems you build with it. The platform has four solutions: 

* Akka SDK, 
* Akka Specify, 
* Akka Verify and 
* Akka Optimize. 

They share one definition of an AI system, one runtime, one ledger and one governance model, so each solution works on what the others produce.

Akka, formerly Lightbend, has run distributed systems in production since 2007. The open-source Akka actor library for the JVM is the lineage of the platform. The platform is a separate product, and this documentation describes the platform.

== How the platform runs

Everything you build runs on the Akka runtime. You operate it yourself, or Akka Automated Operations runs it for you, on Akka's serverless cloud or in your own cloud account. Your services are the same code in every option. See xref:ROOT:about/how-akka-runs.adoc[How Akka runs].
