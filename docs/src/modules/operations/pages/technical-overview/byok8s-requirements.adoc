= BYOK8s requirements
:page-summary: The cloud-agnostic infrastructure requirements for running Akka Automated Operations on a Kubernetes cluster you provide (BYOK8s).

Under Bring Your Own Kubernetes (BYOK8s), you provision the cluster to Akka's specification and install Teleport to grant access. Akka then configures the cluster as an application-plane region, runs smoke tests, and hands it over. This model runs in your cloud or your own data center.

This page lists the cloud-agnostic requirements. For a complete, self-contained setup guide for your cloud, follow the per-cloud page: xref:operations:technical-overview/byok8s-aws.adoc[BYOK8s on AWS], xref:operations:technical-overview/byok8s-azure.adoc[BYOK8s on Azure], or xref:operations:technical-overview/byok8s-gcp.adoc[BYOK8s on GCP]. Each of those includes everything below plus its cloud specifics.
