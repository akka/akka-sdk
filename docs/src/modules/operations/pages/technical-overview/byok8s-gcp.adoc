== GCP specifics

Apply these GCP additions to the requirements above.

* *Database*: use Cloud SQL for PostgreSQL, reachable over private services access.
* *DNS*: use Cloud DNS for the two subdomain zones.
* *Secrets*: use the GCP secrets-store CSI driver provider.
