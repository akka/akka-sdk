== Azure specifics

Apply these Azure additions to the requirements above.

* *Resource providers*: register the resource providers and enable EncryptionAtHost as described on the xref:operations:technical-overview/azure.adoc[Azure page].
* *Database*: use Azure Database for PostgreSQL flexible server.
* *Secrets*: use the Azure secrets-store CSI driver provider.
