link:{url-vllm}[vLLM, window="new"] is an open source serving engine for large language models. It runs models on infrastructure you control.


== vLLM vs Semantic Routing
vLLM and semantic routing serve two completely different layers of an AI system. vLLM is an execution engine that runs and generates text from a model, whereas semantic routing is a traffic director that chooses _which_ prompt goes _where_ based on meaning that isn't derived from another LLM.

In Akka's inference ecosystem, vLLM can be used as a potential target for static or semantic routes.

=== Core differences
The following table compares the roles of vLLM and semantic routing. 

[cols="1,2,2", options="header"]
|===
| Feature
| vLLM engine
| Semantic routing

| Primary role
| Runs and executes large language models.
| Directs incoming user prompts to specific paths.

| How it works
| Generates tokens sequentially using a neural network.
| Compares mathematical vectors, called embeddings, for similarity.

| Compute heavy
| Yes. Requires significant GPU memory and processing power.
| No. A fast and lightweight CPU or GPU operation.

| Output type
| New text, code, or structured JSON data.
| A decision, destination path, or category label.
|===
