= Install the Akka CLI
:page-aliases: operations:cli/installation.adoc, reference:cli/installation.adoc, getting-started:quick-install-cli.adoc, operations:cli/command-completion.adoc, reference:cli/command-completion.adoc

include::ROOT:partial$include.adoc[]

The Akka CLI, `akka` enables you to interact with Akka projects. To install it, follow these steps:

[.tabset]
Linux::
+
--
**Recommended approach**

The recommended approach to install the `akka` CLI on Linux is using the Debian package repository:

[source,bash,subs="attributes"]
----
curl -1sLf \
  'https://downloads.akka.io/setup.deb.sh' \
  | sudo -E bash
sudo apt install akka
----

If the `akka` CLI is already installed, and you want to upgrade to the latest version, you can run:

[source,bash]
----
sudo apt update
sudo apt install --only-upgrade akka
----

**Alternative approach**

[source,bash]
....
curl -sL https://doc.akka.io/install-cli.sh | bash
....

If that fails due to permission issues, use:

[source,bash]
....
curl -sL https://doc.akka.io/install-cli.sh | bash -s -- --prefix /tmp && \
    sudo mv /tmp/akka /usr/local/bin/akka
....

You can pass options to the installer script with `-s --` e.g.:

[source,bash,subs="attributes"]
....
curl -sL https://doc.akka.io/install-cli.sh | bash -s -- --prefix=$HOME --version={akka-cli-version} --verbose
curl -sL https://doc.akka.io/install-cli.sh | bash -s -- -P $HOME -v {akka-cli-version} -V
....

--
macOS::
+
--
**Recommended approach**

The recommended approach to install `akka` on macOS, is using https://brew.sh[brew, window="new"]

[source,bash]
----
brew install akka/brew/akka
----

If the `akka` CLI is already installed, and you want to upgrade `akka` to the latest version, you can run

[source,bash]
----
brew update
brew upgrade akka
----

NOTE: Homebrew 7 and later require third-party taps to be trusted before installing or upgrading from them. If Homebrew warns that the `akka/brew` tap is not trusted, run `brew trust --formula akka/brew/akka` once and then retry.

**Alternative approach**

....
curl -sL https://doc.akka.io/install-cli.sh | bash
....

You can pass options to the installer script with `-s --` e.g.:

[source,bash,subs="attributes"]
....
curl -sL https://doc.akka.io/install-cli.sh | bash -s -- --prefix=$HOME --version={akka-cli-version} --verbose
curl -sL https://doc.akka.io/install-cli.sh | bash -s -- -P $HOME -v {akka-cli-version} -V
....
--
Windows::
+
--
**Recommended approach**

The recommended approach to install the `akka` CLI on Windows is using https://learn.microsoft.com/en-us/windows/package-manager/winget/[winget]:

[source,powershell]
----
winget install Akka.Cli
----

If the `akka` CLI is already installed, and you want to upgrade to the latest version, you can run:

[source,powershell]
----
winget upgrade Akka.Cli
----

**Alternative approach**

. Download the latest version of `akka` from https://downloads.akka.io/latest/akka_windows_amd64.zip[https://downloads.akka.io/latest/akka_windows_amd64.zip]

. Optionally, you can verify the integrity of the downloaded files using the https://downloads.akka.io/latest/checksums.txt[SHA256 checksums].

. Extract the zip file and move `akka.exe` to a location on your `%PATH%`.

--

NOTE: By downloading and using this software you agree to Akka's https://akka.io/legal/privacy[Privacy Policy] and https://trust.akka.io/cloud-terms-of-service[Software Terms of Use].

Verify that the Akka CLI has been installed successfully by running the following to list all available commands:

[source, command window]
----
akka help
----

[#log-in]
== Log in

Before using the `akka` CLI, you must authenticate with your Akka account. To initiate the login process, run:

[source, shell]
----
akka auth login
----

This command opens the Akka console login screen in your default web browser. The CLI will display `Waiting for UI login...` while you authenticate. Once authorization is complete, the CLI returns to the command prompt.

Upon successful authentication:

* If you have one project, it is automatically set as the `current` project.
* If no projects exist, you will need to create one and set it manually.
* If you have multiple projects, you will need to specify the target project manually (see below).

To set your current project:
[source, shell]
----
akka config set project my-project
----

For more authentication options:
[source, shell]
----
akka auth -h
----
You can also refer to the xref:reference:cli/akka-cli/akka_auth.adoc[auth] page.

[#behind-a-proxy]
== Behind a corporate proxy

In corporate environments with HTTP proxy servers that do not support HTTP/2, you may encounter issues since the `akka` CLI uses gRPC. To bypass these limitations, you can configure the CLI to use grpc-web, which works over HTTP/1.1 and HTTP/2.

Log in with grpc-web enabled:
[source, shell]
----
akka auth login --use-grpc-web
----

If you are already logged in but need to switch to grpc-web, configure it with:
[source, shell]
----
akka config set api-server-use-grpc-web true
----

[#command-completion]
== Enable command completion

Completion allows you to hit [TAB] on a partially entered `akka` command and have the shell complete the command, subcommand or flag for you.

[.tabset]
bash::
To load completion in the current bash shell run:
+
[source,bash]
----
source <(akka completion)
----
+
Configure bash to load `akka` completions for each session by adding the following line to your `~/.bashrc` or `~/.profile` file:
+
[source,bash]
----
# add to ~/.bashrc or ~/.profile
source <(akka completion)
----
+
[TIP]
====
Using bash completions with `akka` requires you have bash completions enabled to begin with.
Enable it in your `~/.bashrc` or `~/.profile` file with the following lines:

[source,bash]
----
if [ -f /etc/bash_completion ]; then
  source /etc/bash_completion
fi
----
For definitive details on setting up your shell with auto-completion, see the shell documentation.
====

zsh (e.g. macOS)::
To set up `zsh` shell completion run:
+
[source,zsh]
----
akka completion zsh > "${fpath[1]}/_akka"
compinit
----
+
[NOTE]
====
If shell completion is not already enabled in your environment execute the following:

[source,zsh]
----
echo "autoload -U compinit; compinit" >> ~/.zshrc
----
====

fish::
To set up fish shell completion run:
+
[source,fish]
----
akka completion fish > ~/.config/fish/completions/akka.fish
source ~/.config/fish/completions/akka.fish
----

PowerShell::
To set up shell completion for PowerShell run:
+
[source,powershell]
----
akka completion powershell | Out-String | Invoke-Expression
----
