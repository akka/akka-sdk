Start here to set up a development environment and build your first Akka service. This section is a set of guided tutorials plus a catalog of samples and blueprints you can browse.

== Set up

* xref:getting-started:set-up-dev-env.adoc[Set up your dev env] — three ways to set up: with an AI harness, without AI, or in a container. Do this first.

== Tutorials

Guided, end-to-end walkthroughs that teach by building one thing.

* xref:getting-started:spec-your-first-agent.adoc[Spec-first hello agent] — build an agent with spec-driven development, in Enforced or À la carte mode.
* xref:getting-started:author-your-first-service.adoc[Code-first hello agent] — build the same agent by hand in Java.
* xref:getting-started:planner-agent/index.adoc[Multi-agent tutorial] — orchestrate multiple agents with a workflow.
* xref:getting-started:ask-akka-agent/index.adoc[RAG chat tutorial] — build a retrieval-augmented chat agent.
* xref:getting-started:shopping-cart/index.adoc[Shopping cart tutorial] — build an event-sourced service with entities and views.

== Samples and blueprints

* xref:getting-started:samples.adoc[Samples and blueprints] — browse runnable samples and generate governance-aware systems from blueprints.
