Understanding explains how the Akka Agentic AI Platform works, one mechanism per page, from the components you build to the runtime that runs them. Each page describes a problem every agentic system must handle, how Akka handles it, what Akka guarantees and where the limits are. The task pages in other sections link here for the reasons behind their steps.

== The groups

Foundations:: The vocabulary and the shape of the whole system. xref:platform-model.adoc[] names the parts, xref:request-lifecycle.adoc[] follows one request through all of them, and xref:distributed-systems.adoc[] gives the principles the platform is built on.

Building services:: How the components of a service hold state and do work. See xref:components.adoc[], xref:state-model.adoc[], xref:views.adoc[], xref:durable-execution.adoc[], xref:delivery-guarantees.adoc[] and xref:streaming.adoc[].

Agents:: How agents call models, remember, use tools and work together. See xref:ai-agents.adoc[], xref:agent-memory.adoc[], xref:tools-and-protocols.adoc[], xref:ai-orchestration-patterns.adoc[] and xref:coordination-patterns.adoc[].

Specifications:: How a system is specified, generated and held to its specification. See xref:spec-driven-development.adoc[], xref:specification.adoc[] and xref:conformance.adoc[].

Governance:: How controls run in the runtime and what they leave behind as evidence. See xref:governance-and-the-runtime.adoc[], xref:controls.adoc[], xref:evaluation.adoc[], xref:risk-to-controls.adoc[] and xref:evidence.adoc[].

Models:: How model traffic is captured, graded, routed, served, trained and priced. See xref:models.adoc[], xref:capture-and-grading.adoc[], xref:model-routing.adoc[], xref:model-serving.adoc[], xref:model-training.adoc[] and xref:spend.adoc[].

Runtime and operations:: How services run, scale, stay available and stay secure. See xref:runtime.adoc[], xref:deployment-model.adoc[], xref:multi-region.adoc[], xref:availability.adoc[], xref:automated-operations.adoc[], xref:security-and-identity.adoc[] and xref:observability.adoc[].
