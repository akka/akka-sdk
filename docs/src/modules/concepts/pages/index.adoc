= Understanding

include::ROOT:partial$include.adoc[]

This section introduces the key concepts to understand when developing Akka applications and services.

The xref:concepts.adoc[concepts overview] describes the anatomy of an agentic system and how Akka components fit together. Everything in Akka builds on the xref:distributed-systems.adoc[fundamental principles for distributed systems], and the xref:architecture-model.adoc[architecture model] explains how applications are structured in layers.

Akka manages the operational aspects of your application. To learn how services run across distributed infrastructure and may span multiple _Regions_, see the xref:deployment-model.adoc[deployment model] and xref:multi-region.adoc[multi-region operations].

Components decouple behavior from execution through xref:declarative-effects.adoc[declarative effects], and the xref:state-model.adoc[state model] explains how _Entities_ persist their state. The xref:ai-agents.adoc[AI agents] and xref:ai-orchestration-patterns.adoc[AI orchestration patterns] pages cover how to design agentic systems.
