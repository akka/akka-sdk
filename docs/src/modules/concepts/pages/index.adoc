Understanding gives short explanations of Akka concepts and their main trade-offs. Read the topics relevant to your task; you do not need to read this section in order. Each overview links to the development, testing, training, or operations guide that owns the details.

== The groups

Foundations:: The vocabulary and the shape of the whole system. xref:platform-model.adoc[] names the parts, xref:request-lifecycle.adoc[] follows one request through all of them, and xref:distributed-systems.adoc[] gives the principles the platform is built on.

Building services:: How state and processes behave. See xref:components.adoc[], xref:state-model.adoc[], xref:durable-execution.adoc[], and xref:delivery-guarantees.adoc[].

Agents:: How agents use models, memory, tools, and coordination. See xref:ai-agents.adoc[], xref:agent-memory.adoc[], xref:tools-and-protocols.adoc[], and xref:ai-orchestration-patterns.adoc[].

Specifications:: How requirements, project rules, and acceptance checks fit together. See xref:spec-driven-development.adoc[].

Governance:: How controls run in the runtime and what they leave behind as evidence. See xref:governance-and-the-runtime.adoc[], xref:controls.adoc[], xref:evaluation.adoc[], xref:risk-to-controls.adoc[] and xref:evidence.adoc[].

Models:: How inference and model improvement relate. See xref:models.adoc[] and xref:model-training.adoc[].

Runtime and operations:: How services run, recover, and stay secure. See xref:runtime.adoc[], xref:deployment-model.adoc[], xref:multi-region.adoc[], xref:availability.adoc[], xref:security-and-identity.adoc[], and xref:observability.adoc[].
