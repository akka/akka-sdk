= Akka Runtime release notes
:page-summary: Per-version release notes for the Akka Runtime, and the Akka SDK release that carries each runtime version.

include::ROOT:partial$include.adoc[]

The Akka Runtime executes your service. You do not declare it as a dependency. Each Akka SDK release pins one runtime version, and a deployed service runs the runtime version that the Akka Platform provides.

Each page below covers one runtime release. Read the page for a version to find what changed, whether a change affects a service that is already running, and which Akka SDK release includes it.

For a single chronological list covering the Akka SDK, the Akka CLI, the runtime, and the Akka libraries, see xref:release-notes.adoc[Release notes].
