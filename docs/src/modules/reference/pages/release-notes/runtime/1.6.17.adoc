== Changes

* Views and Eventing: optimization of views and consumers that catch up over a long event backlog
* gRPC endpoints: a `google.protobuf.Any` field with an unknown type no longer fails a debug traced request
* Agents: tool results and messages with several or non-text contents no longer fail a debug traced request
* TestKit: every trace is a debug trace
