= Akka 26.11 Released

Dear hakkers,

We are excited to announce the availability of the Akka libraries 26.11 release, setting a new baseline of Akka library versions that go together.

Akka 26.11 consists of the following module versions:

* Akka core 2.11.0
* Akka HTTP 10.8.0
* Akka Management 1.7.0
* Akka Projections 1.7.1
* Akka gRPC 2.6.0
* Akka Persistence Cassandra 1.4.1
* Akka Persistence DynamoDB 2.1.1
* Akka Persistence JDBC 5.6.0
* Akka Persistence R2DBC 1.4.1
* Alpakka 11.0.2
* Alpakka Kafka 9.0.0
* Akka Diagnostics 2.3.0
* Akka Insights 2.23.0

These versions also consistently upgrade to *Jackson 2.21.8*, of the Jackson 2.21 long-term-support line.

As reference of versions that go together for Akka 26.11, please see https://doc.akka.io/libraries/akka-dependencies/26.11/[Akka library versions 26.11].

The `akka-dependencies` BOM 26.11.1 contains these versions. Use it rather than 26.11.0. Akka Persistence R2DBC 1.4.1 and Alpakka 11.0.2 fix dependencies that Maven resolved to older versions. With 26.11.0, Maven users of Akka Persistence R2DBC on Linux x86_64 could not connect to the database.

== Removal of deprecated APIs

Akka core 2.11.0 removes all APIs that Akka 2.10.0 or earlier deprecated. The most notable removals are:

* The LevelDB journal, the shared LevelDB journal and the LevelDB read journal. Use another journal, such as Akka Persistence R2DBC. For tests, use the in-memory journal, together with the journal proxy when several actor systems share one journal.
* `ActorMaterializer` and `ActorMaterializerSettings`. Use `Materializer`, and configure streams with the `akka.stream.materializer` config or with attributes.
* Stream operators such as `Source.fromFuture`, `Source.lazily`, `Flow.lazyInit`, `Source.setup` and `FileIO.fromFile`.
* The `java.util.logging` integration in `akka.event.jul`. Use SLF4J.

The https://doc.akka.io/libraries/akka-core/current/project/migration-guide-2.10.x-2.11.x.html[migration guide] lists every removed API and its replacement.

== Jackson 2.21

The Akka libraries now depend on the Jackson 2.21 long-term-support line. Jackson 2.18, which Akka 25.10 used, gets no further updates after January 2027.

== License key

Akka requires a license key for use in production.

Read about the motivation in the blog post https://akka.io/blog/akka-license-keys-and-no-spam-promise[Akka License Keys && a No SPAM Promise].

Obtain a free key at https://akka.io/key.

== Security Updates

We run automated security vulnerability and license policy scanning of dependencies. Several dependencies have been updated to fix security vulnerabilities and keep up with latest improvements.

The following CVE’s are addressed in this build.

* https://nvd.nist.gov/vuln/detail/CVE-2025-66566[CVE-2025-66566] (lz4-java)
* https://nvd.nist.gov/vuln/detail/CVE-2026-45292[CVE-2026-45292] (OpenTelemetry, in Akka Insights)

Akka HTTP also has several fixes that harden HTTP/2 and request parsing.

== Bug fixes

* Memory leak of completed stages and connections in the stream interpreter
* HTTP/2 connection unusable after a bad request response in Akka HTTP
* Akka gRPC clients abandon connections stuck in connecting, after a new `connecting-timeout`
* Atomic writes of several events in Akka Persistence DynamoDB could lose events after a timed out transaction

== Other improvements

* Split Brain Resolver downs all nodes when at least half of the members are indirectly connected
* Server interceptor API in Akka gRPC
* Configurable HTTP/2 header block limits in Akka HTTP
* Optional end-to-end keep alive for gRPC event streams and replication in Akka Projections
* Custom journal table and extra journal columns in Akka Persistence R2DBC
* Instrumentation SPI in Akka Persistence DynamoDB
* Couchbase collections in Alpakka
* Artifact BOMs for all modules

== Dependency updates

* Jackson 2.21.8
* Netty 4.2
* Kafka Clients 4.4.0
* grpc-java 1.85.0

== Compatibility

* Akka Persistence R2DBC 1.4 no longer supports SQL Server. Users of SQL Server must stay on Akka Persistence R2DBC 1.3.x.
* Akka Persistence R2DBC 1.4 uses Netty 4.2, which changes the default buffer allocator. To keep the old allocator, start the JVM with `-Dio.netty.allocator.type=pooled`.
* Alpakka 11.0.0 removes the Pravega, IronMQ, Spring Web and Huawei Push Kit connectors.
* Akka Insights 2.23.0 only supports Akka 26.11. Stay on Akka Insights 2.22.x with Akka 25.10.
* Apart from the removed APIs and connectors, the modules of Akka 26.11 are backwards compatible with Akka 25.10.
* Rolling update of Akka Cluster is fully supported.

Akka libraries now depend on Scala 2.13.18. Because of this, Scala sbt projects on Scala 2.13 will need to bump their Scala version to 2.13.18 to avoid errors from sbt.
