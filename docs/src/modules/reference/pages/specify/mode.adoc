= /akka:mode

Switch between the Enforced and À la carte conformance modes.

== Usage

[source]
----
/akka:mode enforced
/akka:mode a-la-carte
----

== Description

Rewrites the available command set to match the target mode and prompts you to restart your assistant so the new command menu loads. A developer can switch only within the modes the organization allows; if the organization has locked the mode, the command refuses and says so. Switching out of Enforced mode is recorded.

See xref:sdk:spec-driven-development.adoc#choosing-your-mode[Conformance modes] for what each mode does.
