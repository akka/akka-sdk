= akka optimize registry models versions

One named model's versions, narrowed by base model or by producer

== Synopsis

List the versions of one named model.
Narrow with one of:   --base-model:        a base model, as a repository or as a version reference.
--produced-by-kind   --produced-by-id:    every version one process produced.
Give both or neither.

The narrowings are different questions, so the registry refuses a request that states both.
A training run's producer id is the run id for the model it ended with, and runId#step for a checkpoint.

----
akka optimize registry models versions NS/NAME [flags]
----

== Examples

----
  # List every version
  akka-optimize registry models versions triage/classifier

  # List the versions over one base model
  akka-optimize registry models versions triage/classifier --base-model Qwen/Qwen3-0.6B

  # Read the version a run ended with, as JSON
  akka-optimize registry models versions triage/classifier \
    --produced-by-kind run --produced-by-id run-4f3a --json reference
----

== Options

----
      --base-model string         List the versions over one base model, as a repository or a version reference
  -h, --help                      help for versions
      --produced-by-id string     List what the process with this id produced
      --produced-by-kind string   List what this kind of process produced, such as 'run'
----
