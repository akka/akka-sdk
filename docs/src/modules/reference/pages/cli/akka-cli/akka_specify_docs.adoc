= akka specify docs

Show where the generated project documentation is, and optionally open it.

== Synopsis

Locate the rendered project documentation produced by the /akka:docs command.

/akka:docs generates a self-contained docs/index.html -- a component reference with entity and interaction diagrams -- into the project's docs/ folder.
This command prints its location and, with --open, opens it in your default browser.

----
akka specify docs [flags]
----

== Options

----
      --dir string   project directory (default: current)
  -h, --help         help for docs
      --open         open the documentation in your default browser
----
