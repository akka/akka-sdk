= akka optimize models get

One model version, with its training, serving, routing and price

== Synopsis

Read a model version from the registry, with what each other service knows about it:

training  the run that produced it, its dataset, and the newest score per dataset and grader   serving   the trainer's endpoints that serve it, and the name a request calls it by   routing   the destination records that name it, the rules that send to them, and the             manifest in force where it sends to one   price     the pricing catalog version in force, and its entry for each of the served names

A part whose service does not answer within 10s, or within --timeout where you state one, is shown as unavailable, and the command still succeeds.
-o json prints each part as its service answered it.

A reference is one string: NS/NAME for the named artifact, NS/NAME:v2 for a version, NS/NAME:serving for the version an alias points at, and NS/NAME@sha256:...
for a version by digest.
NS/NAME where a version is wanted is the newest version.

[source,shell]
----
akka optimize models get NS/NAME[:REF] [flags]
----

== Examples

[source,shell]
----
  # Read one version
  akka optimize models get triage/classifier:v2

  # Read the version an alias points at, as JSON
  akka optimize models get triage/classifier:serving -o json
----
