= akka optimize spend

What a period consumed, what it cost, and what one conversation cost

== Synopsis

Every figure is computed over the interaction records the capture chain published and the prices in force when each exchange was served.

A window is whole UTC hours, `--from` inclusive and `--to` exclusive.
The service refuses one it cannot answer and names what would clear it;
nothing is widened here.

Money is reported as the digits the service computed.
A figure with no value states why it has none and never reads as zero.
