= akka optimize datasets create

Register a dataset from a JSONL file

== Synopsis

Register a dataset from a JSONL file containing chat-formatted examples.

Datasets are identified by content hash.
Use --name to assign or update a convenient alias name for the dataset.

Examples can reference local image files by relative path.
Any missing images are uploaded automatically unless --no-upload is specified.

----
akka optimize datasets create -f FILE [flags]
----

== Examples

----
  # Register a dataset from a JSONL file
  akka-optimize datasets create -f examples.jsonl

  # Register a dataset with an alias name
  akka-optimize datasets create -f examples.jsonl --name commit-train

  # Check for missing images without uploading
  akka-optimize datasets create -f examples.jsonl --no-upload
----

== Options

----
  -f, --file string   Path to the chat-format JSONL file
  -h, --help          help for create
      --name string   Assign an alias name to the registered dataset
      --no-upload     Check and report missing images without uploading or registering
----
