= akka optimize routing-experiments hold

Stop advancing;
writes nothing

== Synopsis

An action that writes the rule or canary is finished by the service.
When it is still running as the answer comes, the answer says so;
read the experiment with get to see how it finished.
When its write failed on every attempt, send the action again.
A roll back replaces a failed start or advance.
Any other action is refused while one is unfinished.

[source,shell]
----
akka optimize routing-experiments hold NAME [--reason TEXT] [flags]
----

== Options

[source,text]
----
  -h, --help                 help for hold
      --if-revision string   only act if the experiment is still at this revision
      --reason string        why; recorded with the action
----
