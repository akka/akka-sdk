= akka specify run close

Close a run: its end, HEAD, the files changed and its outputs.

== Synopsis

[Incubating] Close an open run.
The receipt records the time, HEAD, the files changed since the run's start commit and the outputs the command names with --file.
A Conform close keeps the /akka:conform manifest beside the receipt with the engine's verdict: the file --manifest names, or without it the manifest written from the results the last akka specify conform recorded.
--outcome says how the run ended: ok;
failed or stopped, with --error saying why;
or waiting, with --question asking a person what the command needs before it runs again.
It is required, except in the console run AKKA_RUN_ID names, where it defaults to ok.
The idea then waits on its owner;
the answer is in idea show --json under questions.
In a command the console started (AKKA_RUN_ID naming the run), only that run is closed, and only its outputs, tasks, manifest and a worse outcome are recorded: the run is left open for the console to end with the outcome of the process it started.
--policy and --dir are refused there.

[source,shell]
----
akka specify run close [flags]
----

== Options

[source,text]
----
      --dir string         project directory (default: current)
      --error string       why a failed or stopped run ended
      --file stringArray   a file or folder in the project the command produced; repeat for each; one outside the project is left out
  -h, --help               help for close
      --idea string        the idea holding the run (default: found by the run's id)
      --json               print the run as JSON
      --manifest string    the /akka:conform manifest file, a path in the project (Conform runs; default, and always in a command the console started: written from the recorded results)
      --outcome string     how the run ended: ok, failed, stopped or waiting; required but in the console run AKKA_RUN_ID names
      --policy string      path to an org governance policy-as-code file (policy.yaml)
      --question string    with --outcome waiting, what the run asks a person
      --run string         the run's id
      --task stringArray   a task the run worked on; repeat for each
----
