= akka optimize training evaluations get

Display details for an evaluation

== Synopsis

Display the configuration, status, and summary score for an evaluation.

----
akka optimize training evaluations get EVALUATION [flags]
----

== Examples

----
  # Display evaluation details
  akka-optimize training evaluations get 9c2e4b7a1d63f085

  # Follow progress until the evaluation finishes
  akka-optimize training evaluations get 9c2e4b7a1d63f085 --follow

  # Extract the mean score using jq
  akka-optimize training evaluations get 9c2e4b7a1d63f085 --jq .report.meanScore
----

== Options

----
      --exit-status   Exit with a non-zero status if execution fails or is cancelled. Requires --follow
      --follow        Stream status updates until the evaluation finishes
  -h, --help          help for get
----
