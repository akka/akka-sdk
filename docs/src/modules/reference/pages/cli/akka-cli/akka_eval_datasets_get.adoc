= akka eval datasets get

One dataset: what it holds, what scores it, and every version it has had.

== Synopsis

The head describes the current version. The table lists version history, most recently imported first.

----
akka eval datasets get ID [flags]
----

== Options

----
  -h, --help   help for get
----
