= akka optimize training runs tensorboard

Open a run's training curves in TensorBoard

== Synopsis

Fetch a run's TensorBoard event files and open them in a local TensorBoard.

The training loop writes every figure it measures per step to event files, and ships them to the run's storage as they grow.
This command mirrors them to a local directory and starts "tensorboard --logdir" on it.
While the run is still training the files are fetched again every few seconds, so the curves move.

TensorBoard is started from PATH.
Install it with "pip install tensorboard" or "uv tool install tensorboard".
Pass --sync-only to fetch the files and start nothing, for a TensorBoard you run yourself.

----
akka optimize training runs tensorboard RUN [flags]
----

== Examples

----
  # Open the curves of a run
  akka-optimize training runs tensorboard 7d496e82c3a15f04

  # Fetch the event files into a directory of your choosing, without starting TensorBoard
  akka-optimize training runs tensorboard 7d496e82c3a15f04 --dir ./curves --sync-only
----

== Options

----
      --dir string   where the event files go; default is a directory under the system temp
  -h, --help         help for tensorboard
      --port int     the port TensorBoard listens on (default 6006)
      --sync-only    fetch the event files and start no TensorBoard
----
