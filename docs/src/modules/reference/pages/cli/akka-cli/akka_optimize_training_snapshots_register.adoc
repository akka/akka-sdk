= akka optimize training snapshots register

Register snapshot weights as a candidate model

== Synopsis

Register a committed snapshot's weights as a candidate model.

The command outputs a model ID that "training evaluations start --model" scores like any other model.
Registering does not alter the run that produced the snapshot and does not duplicate its weights in the catalog.

The model ID is derived from the snapshot, so registering the same snapshot again returns that same ID.
SNAPSHOT may be a complete snapshot ID or an unambiguous prefix.

A snapshot holding only training state is refused.
It can be resumed and branched from, but no adapter has been exported from it.

Registration is prepared in durable steps and is accepted before it completes.
Use "training snapshots candidate" to check its progress.
Registration retains the source only while it copies the weights, after which the source is swept under the run's own keep counts.
Use "training snapshots pin" to retain a source you intend to branch from later.

----
akka optimize training snapshots register SNAPSHOT [flags]
----

== Examples

----
  # Register a snapshot as a candidate model
  akka-optimize training snapshots register 3f2a9c71bd04e5a2...

  # Extract the registered model ID using jq
  akka-optimize training snapshots register 3f2a9c71bd04e5a2... --jq .modelId
----
