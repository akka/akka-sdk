= akka optimize training snapshots get

Show one committed snapshot

== Synopsis

Display one snapshot, by full ID or by an unambiguous prefix.

The report covers where the snapshot came from, which artifact kinds it holds, the manifest digest identifying each kind's bytes, the engine that wrote them, and the model shape they were written for.
A branch is checked against those values, so this is what a refused branch is read against.

----
akka optimize training snapshots get SNAPSHOT [flags]
----

== Examples

----
  # Display a snapshot
  akka-optimize training snapshots get 3f2a9c71bd04

  # Extract the weights manifest digest using jq
  akka-optimize training snapshots get 3f2a9c71bd04 \
    --jq '.artifacts[] | select(.kind=="weights") | .manifestDigest'
----
