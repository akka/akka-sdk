= akka eval

Datasets, experiments and the evaluators that grade them.

== Synopsis

An experiment is one execution of one dataset version against one target with one set of evaluators.

An evaluator never turns a failure into a low score.
It reports inconclusive when it has nothing to read, and neither that nor its own breakage enters a pass rate.

----
akka eval [command]
----
