= akka eval

Datasets, campaigns and the scorers that grade them.

== Synopsis

A campaign is one execution of one dataset version against one target with one set of scorers.

A scorer never turns a failure into a low score.
It reports inconclusive when it has nothing to read, and neither that nor its own breakage enters a pass rate.

----
akka eval [command]
----
