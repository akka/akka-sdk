= akka specify probes findings

Print draft findings for what the latest probe run established.

== Synopsis

Prints finding lines drafted from .akka/discovery/run.json and the result files of the probes that ran, and a question line for each gap a probe reported.
Each draft is status observed with rung exercised: +++<probe>+++.
A person confirms.+++</probe>+++

Identifiers continue from the highest one with the same code under discovery/: F-`- with --topic, F- without.
A claim already recorded is left out.`

With --write research, system-map or behaviour the lines are appended to that file of the topic.
Nothing is written otherwise, and existing text is never changed.

[source,shell]
----
akka specify probes findings [flags]
----

== Options

[source,text]
----
      --dir string     project directory (default: current)
  -h, --help           help for findings
      --topic string   the discovery topic whose code the identifiers carry (default: project level)
      --write string   append to the topic's research, system-map or behaviour file
----
