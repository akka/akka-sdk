= akka local services run

Compile a service and run it under the running local runtime.

== Synopsis

The `akka local services run` command compiles the Maven service in DIRECTORY (the current directory by default) and starts it in the background under the local runtime that `akka local start` started.
A service already running from that directory is stopped first.
The command does not start the local runtime;
when it is not running, the command fails.

[source,shell]
----
akka local services run [DIRECTORY] [flags]
----

== Examples

[source,shell]
----
akka local services run ./shopping-cart
----
