= akka optimize training comparisons

Compare a source snapshot with selected branch models

== Synopsis

A comparison scores the exact source snapshot and selected descendant branch models under one resolved dataset, grader definition, and completion-token ceiling.

The source snapshot is registered as a protected candidate automatically.
Each model has its own evaluation status.
Complete comparisons contain evidence for every model.
Partial comparisons keep successful results beside failed, refused, or uncertain targets and do not name a winner.
Training spend covers whole runs and is kept separate from evaluation spend.
