= akka models delete

Delete the resources a model descriptor names.

== Synopsis

Deletes every resource of the descriptor, in reverse dependency order: endpoints first, then models, then allocations, so nothing is ever torn out from under something that still uses it.
A resource already absent is skipped, so delete is safe to repeat.

The key secret an endpoint names is deliberately left alone: keys are handed to clients, and destroying them is its own decision (`akka secrets delete`), not a side effect.

----
akka models delete [flags]
----

== Examples

----
akka models delete -f runner.yaml
akka models delete -f runner.yaml --force
----

== Options

----
  -f, --file string      The descriptor file; stdin when omitted.
      --force            Delete without confirmation.
  -h, --help             help for delete
      --owner string     the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string   project to use if not using the default configured project
      --region string    region to use if project has more than one region
----
