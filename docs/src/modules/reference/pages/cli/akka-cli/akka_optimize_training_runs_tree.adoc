= akka optimize training runs tree

Display a tree of runs branched from a root run

== Synopsis

Display the tree of descendant runs branched from ROOT across all generations.

Unlike "training runs branches", which lists only direct child runs, this command traverses the full branch hierarchy and indents each child run beneath its parent.

SOURCE STEP indicates the checkpoint step of the parent run where the branch began.
It does not reflect the current step or progress of the child run, which counts updates starting from zero.

Use --depth to restrict traversal to a specific number of generations below ROOT.
By default, all generations are traversed.

Results are populated from asynchronous run projections;
recently created runs may take a moment to appear.

----
akka optimize training runs tree ROOT [flags]
----

== Examples

----
  # Display the branch tree below a run
  akka-optimize training runs tree 7d496e82c3a15f04

  # Restrict traversal to direct children
  akka-optimize training runs tree 7d496e82c3a15f04 --depth 1

  # Extract all run IDs using jq
  akka-optimize training runs tree 7d496e82c3a15f04 --jq '.. | .runId? // empty'
----

== Options

----
      --depth int   Number of generations below ROOT to traverse (0 traverses all generations)
  -h, --help        help for tree
----
