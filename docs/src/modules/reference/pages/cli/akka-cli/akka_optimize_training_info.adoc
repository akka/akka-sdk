= akka optimize training info

Report the trainer's configuration and build

== Synopsis

Reports how this trainer is configured, which build is answering, and what its start did.

Exits non-zero when the service is not answering, and when its start did not complete, so a readiness loop can wait on it.
A start that did not complete leaves work the service will not pick up again before a restart;
`Startup` names which step and what it said.

`--jq` reads one value out, as in `--jq .backend`.

----
akka optimize training info [flags]
----
