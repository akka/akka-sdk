= akka eval run

Run the local eval campaigns.

== Synopsis

Wraps the Maven invocation that runs every campaign under `src/eval/`.
Streams output to stdout and forwards the Maven exit code.

Use this command in CI in place of the raw Maven line.

----
akka eval run [flags]
----

== Options

----
      --goals string   the Maven goal to run under the eval profile (default "verify")
  -h, --help           help for run
----
