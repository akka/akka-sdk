= akka optimize training runs engine-config

Display the configuration a training run's engine was given

== Synopsis

Display what a training run's job gave its engine, and what the engine made of it.

The job writes this once, before the first step.
"requested" is what it built from the run's settings.
"resolved" is the engine's whole configuration with its own defaults filled in, and the adapter as it was attached to the model.
The table lists each requested setting, and marks one the engine resolved to a different value.
The JSON output carries both parts in full.
Not found where the job has not written it yet.

----
akka optimize training runs engine-config RUN [flags]
----

== Examples

----
  # Display what a run's engine was given
  akka-optimize training runs engine-config 7d496e82c3a15f04

  # Read one setting as the engine resolved it, defaults included
  akka-optimize training runs engine-config 7d496e82c3a15f04 --jq .resolved.config.adam_beta1
----
