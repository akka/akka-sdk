= akka specify status

Show the exit-condition Definition-of-Done manifest.

== Synopsis

[Incubating] Resolve the exit-condition library against an org governance floor (policy-as-code) and the project's own state, then render the dense Definition-of-Done manifest: every condition grouped by tier, with lock, on/off, status, and provenance.
Struck, waived, and signed-off conditions reflect the project state, so this view agrees with 'conform'.
Auditors are not run here -- use 'akka specify conform' for evaluated statuses.

With --policy pointing at an org 'akka-specify-governance' policy.yaml you can see conditions lock (ALWAYS-APPLY), defaults get struck (turned off), and corporate exit conditions appear.

Examples:   akka specify status   akka specify status --policy ./policy.yaml

----
akka specify status [directory] [flags]
----
