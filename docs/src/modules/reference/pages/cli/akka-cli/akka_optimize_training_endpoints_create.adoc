= akka optimize training endpoints create

Make a model answerable at an endpoint

== Synopsis

Bring up an endpoint for a model, or attach the model to the endpoint already serving its base model.

--model takes a selected base model, by repository or registry version, or a candidate, by registry reference NS/NAME[:VERSION].
--project is what the endpoint's devices count against, and defaults to the training project the model names.
A candidate names the training project it was trained for, so it needs no --project;
a base model names none, so serving one takes the flag.
Given for a candidate, it must be the training project the candidate already names.

Where nothing is serving the base model yet, this claims devices and the endpoint reports STARTING until the process answers.
Where something is, the model attaches to it and is answerable at once.

The command returns straight away.
Use --wait to return once the endpoint answers, which is what a script needs before it sends anything.

--timeout bounds that wait and leaves the endpoint alone when it expires, and zero waits without a deadline.
It means nothing without --wait, so giving it alone is refused.

[source,shell]
----
akka optimize training endpoints create --model MODEL [--project PROJECT] [flags]
----

== Examples

[source,shell]
----
  # Serve a base model, which belongs to no training project
  akka optimize training endpoints create --model Qwen/Qwen3-8B --project triage

  # Serve a candidate over the same base model, under the training project it was trained for
  akka optimize training endpoints create --model triage/candidate:v3

  # Return once it answers
  akka optimize training endpoints create --model triage/candidate:v3 --wait
----

== Options

[source,text]
----
  -h, --help               help for create
      --model string       Selected base model or candidate to serve, as a registry reference NS/NAME[:VERSION]. With --project, NAME[:VERSION] names a model in that project's namespace
      --project string     Training project whose GPU quota the endpoint's devices count against. Defaults to the training project the model names, and must agree with it when given
      --timeout duration   Maximum time to wait for the endpoint; zero waits without a deadline; requires --wait (default 15m0s)
      --wait               Wait until the endpoint answers
----
