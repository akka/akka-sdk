= akka optimize training base-models select

Select a base model for runs, evaluations, and endpoints

== Synopsis

Select an allowed base model.

Selecting registers the model.
On a deployment configured to cache weights during selection, it also starts downloading them.
The command returns after the selection request is accepted.
To follow preparation, read the entry with `base-models get` or use --wait.

--wait covers admission and any download configured for selection.
On a deployment that downloads weights only when work starts, it returns as soon as the selection is ready.

Runs, evaluations, and endpoints can start as soon as the model is selected.
If its weights are not cached, the first work that needs them downloads them.
A cached selection uses storage but no standing compute.

The entry reports what the selection cached.
It does not report weights that a job downloaded afterwards.

----
akka optimize training base-models select BASE_MODEL [flags]
----

== Examples

----
  # Select a model
  akka-optimize training base-models select Qwen/Qwen3-8B

  # Then watch it prepare
  akka-optimize training base-models get Qwen/Qwen3-8B

  # Or wait for admission and any download configured for selection
  akka-optimize training base-models select Qwen/Qwen3-8B --wait
----

== Options

----
  -h, --help               help for select
      --timeout duration   Maximum time to wait for admission and selection; requires --wait (default 30m0s)
      --wait               Wait for admission and any weight download configured for selection
----
