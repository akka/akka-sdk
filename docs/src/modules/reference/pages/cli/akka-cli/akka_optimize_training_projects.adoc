= akka optimize training projects

Manage training projects

== Synopsis

A training project defines a training target, specifying the dataset and grader used to evaluate candidate models.

A training project's name is the registry namespace everything it registers goes under, so it is set at creation and never changes.
Training project commands accept either training project name or ID.

A candidate or a champion is an alias on a named model in the artifact registry.
Set one with "akka optimize registry models alias set NS/NAME:champion --version vN".

== Examples

[source,shell]
----
  # Create a training project with an evaluation dataset
  akka optimize training projects create commit-router --dataset eval-set

  # Compare candidate model scores against the baseline
  akka optimize training projects scores commit-router
----
