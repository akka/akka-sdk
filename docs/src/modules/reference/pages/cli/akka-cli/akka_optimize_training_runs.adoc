= akka optimize training runs

Manage training runs, snapshots and child runs

== Synopsis

A training run trains a model using a specified dataset and configuration.

To train and evaluate a model in a single multi-stage workflow, use training pipelines.

Each plan submission starts a new training run.
Submitting an identical plan starts a distinct run for that configuration.

A run commits snapshots as it trains.
"snapshots" lists them, and "branch" submits a child run from one source snapshot with a budget of additional optimizer updates.
"sweep" submits one child run for each point of a parameter grid from a single source snapshot, and can score the source against the resulting fan.
"branches" lists direct child runs, "tree" displays descendants across all generations, and "ancestry" traces a run back to its root.

== Examples

----
  # Submit a plan and wait for the run to finish
  akka-optimize training runs start -f plan.json --wait

  # List active and incomplete runs
  akka-optimize training runs list --phase open

  # Follow an existing run and exit with a non-zero status if it fails
  akka-optimize training runs wait 7d496e82c3a15f04 --exit-status

  # Display details for a run in JSON format
  akka-optimize training runs get 7d496e82c3a15f04 -o json

  # List the snapshots a run committed
  akka-optimize training runs snapshots 7d496e82c3a15f04
----
