= akka optimize training projects create

Create a new training project

== Synopsis

Create a training project and display its assigned ID.

The --dataset and --grader flags specify the evaluation dataset and grader used to score candidate models.
--grader applies with --dataset, and defaults to json-label-match.
--grader-instructions records the instructions a model: grader is asked under, so the scores table shows only evaluations started with the same --grader and --grader-instructions.
You can also configure or update these settings later using "training projects set-evaluation".

[source,shell]
----
akka optimize training projects create NAME [flags]
----

== Examples

[source,shell]
----
  # Create a training project
  akka optimize training projects create commit-router

  # Create a training project with evaluation settings
  akka optimize training projects create commit-router \
    --dataset eval-set --grader json-label-match
----

== Options

[source,text]
----
      --dataset string               Evaluation dataset, by registry reference
      --grader string                Grader specification: json-label-match, model:NS/NAME[:VERSION], or http:URL
      --grader-instructions string   Instructions a model: grader is asked under, in place of the ones it would otherwise get
  -h, --help                         help for create
----
