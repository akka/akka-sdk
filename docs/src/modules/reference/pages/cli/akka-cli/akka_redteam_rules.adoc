= akka redteam rules

Rules declared in the project's red-team campaigns.

== Synopsis

Lists rules declared under red team, optionally filtered by hazard.

----
akka redteam rules [command]
----

== Options

----
      --hazard string   restrict to rules covering the named hazard
  -h, --help            help for rules
----
