= akka optimize training comparisons list

List comparisons

== Synopsis

List comparisons, newest first.

A comparison ID is derived from its source snapshot and its submission token rather than assigned, so an ID that has been lost is otherwise only reachable by repeating the submission that created it.

MODELS counts what is being compared, the source among them.
How each one scored belongs to its own evaluation;
read it with "comparisons get".

--limit bounds how many are listed, a hundred by default.
Nothing deletes a comparison, so a deployment that has made thousands would otherwise print all of them.
--source lists one snapshot's comparisons whole.

----
akka optimize training comparisons list [flags]
----

== Examples

----
  # List the hundred newest comparisons
  akka-optimize training comparisons list

  # List more of them
  akka-optimize training comparisons list --limit 250

  # List the comparisons of one source snapshot
  akka-optimize training comparisons list --source 3f2a9c71bd04
----

== Options

----
  -h, --help            help for list
      --limit int       How many comparisons to list, newest first; the service's default is 100
      --source string   List only the comparisons of one source snapshot, by ID or an unambiguous prefix
----
