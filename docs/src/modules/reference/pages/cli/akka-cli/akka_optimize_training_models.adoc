= akka optimize training models

Import a merged model trained elsewhere, so a KalixModel can serve it

== Synopsis

Import a merged model trained outside Optimize as a registered model version.

The service takes the model's files, checks the weights' headers, the configuration and the tokenizer, places the files in the region's model storage under the serving project, and registers them as a version of the model you name.
A KalixModel in the serving project then serves the model on a remote pool.
