= akka organizations identity-providers update oauth

Update an OAuth/OIDC workload identity provider for the current (or specified) organization

== Synopsis

The `akka organizations identity-providers update oauth` command updates a workload identity provider for the given organization in Akka.

As with creation, Akka performs OpenID discovery and JWKS keyset validation against the issuer before persisting the update.

----
akka organizations identity-providers update oauth PROVIDER-ID [flags]
----

== Options

----
      --claim-mapping-add stringToString   Adds (or updates) a mapping from a JWT claim to a named attribute on the workload identity principal, in the form attribute=claim. May be specified multiple times. (default [])
      --claim-mapping-remove strings       Removes a claim mapping by its attribute name. May be specified multiple times.
  -h, --help                               help for oauth
      --issuer string                      The HTTPS URL of the OIDC token issuer, e.g. https://token.actions.githubusercontent.com.
      --organization string                name or ID for organization
      --subject-claim string               The JWT claim whose value is used as the workload identity subject, e.g. sub.
----
