= akka optimize eval init

Add the eval source root to a project

== Synopsis

Writes the eval tree -- scorers by family, datasets, rubrics, baselines -- into the existing project's src/test/java and adds the evalkit dependency to the project pom at test scope.
Campaigns are ordinary JUnit tests gated on -Deval=true, so `mvn verify` compiles them without running them;
`mvn verify -Deval=true` runs them.

Additive: a file already present is left alone and reported, because this overlays a tree that may hold scorers and datasets somebody wrote.
--force replaces them, after backing up what it replaces.
The dependency edit is idempotent -- the pom is left alone when the dependency is already declared, and a backup is written to pom.xml.backup before any change.

Run it again to take a newer scaffold;
the parts you have written stay yours.

----
akka optimize eval init [DIRECTORY] [flags]
----

== Options

----
      --force            replace files that are already there
      --from string      a scaffold archive on disk, instead of downloading one
  -h, --help             help for init
      --package string   the Java package to write eval sources under (defaults to <groupId>.eval)
      --source string    where to download the scaffold from
----
