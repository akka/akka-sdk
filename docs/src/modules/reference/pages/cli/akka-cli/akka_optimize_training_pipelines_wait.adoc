= akka optimize training pipelines wait

Wait for a training pipeline to finish

== Synopsis

Stream stage progress updates for a training pipeline until it reaches a terminal phase.

By default, the command exits with code 0 upon reaching COMPLETED, FAILED, or CANCELLED.
Use --exit-status to return a non-zero exit code if the pipeline ends in FAILED or CANCELLED.

Use --timeout to specify a maximum duration to wait.
If the timeout expires, the command exits with a non-zero status while the pipeline continues in the background.

Interrupting with Ctrl-C stops following progress without cancelling the pipeline.

When using -o json, one snapshot of the pipeline is streamed to stdout as line-delimited JSON per update, in the same shape the pipeline's own SSE endpoint sends, stage by stage.
Use -o json-compact to keep each snapshot on one line when a script reads the output line by line.

----
akka optimize training pipelines wait PIPELINE [flags]
----

== Examples

----
  # Wait for a pipeline to finish
  akka-optimize training pipelines wait 3f9a21c4d08b7e56

  # Wait up to 4 hours and exit with non-zero status if the pipeline fails
  akka-optimize training pipelines wait 3f9a21c4d08b7e56 --timeout 4h --exit-status

  # Stream stage snapshots as JSON
  akka-optimize training pipelines wait 3f9a21c4d08b7e56 -o json-compact | jq -c .
----

== Options

----

  -h, --help               help for wait
