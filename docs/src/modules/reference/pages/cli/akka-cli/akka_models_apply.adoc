= akka models apply

Apply a model descriptor to the project's region.

== Synopsis

Applies the resources of a model descriptor: multi-document YAML, each document carrying resource, resourceVersion: v1, metadata.name and a spec in the platform's own schema.
Today the descriptor holds AcceleratorAllocation resources;
Model and ModelEndpoint follow.

Apply is create-or-update by name.
The region admits every change - device fit against the pool is decided there, not here - so --dry-run runs the server's full admission without persisting anything.

----
akka models apply [flags]
----

== Examples

----
akka models apply -f allocation.yaml
akka models apply -f allocation.yaml --region aws-us-east-2 --dry-run
cat allocation.yaml | akka models apply
----

== Options

----
      --dry-run          Run the region's admission without persisting anything.
  -f, --file string      The descriptor file; stdin when omitted.
  -h, --help             help for apply
      --owner string     the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string   project to use if not using the default configured project
      --region string    region to use if project has more than one region
----
