= akka eval campaigns

One dataset version, one target, one set of scorers.

== Synopsis

A campaign is one execution of a plan. Aliased to `experiments` for one release cycle.

----
akka eval campaigns [command]
----

== Options

----
  -h, --help   help for campaigns
----
