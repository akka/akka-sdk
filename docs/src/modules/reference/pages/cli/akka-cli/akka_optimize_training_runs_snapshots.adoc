= akka optimize training runs snapshots

List a run's committed snapshots

== Synopsis

List the snapshots a training run left in the catalog.

The list contains saves the catalog verified and committed.
The configured interval does not show whether a save actually happened.
Bytes left by an interrupted publication are not a snapshot.

ARTIFACTS shows how you can use each snapshot.
Use weights to register a candidate model or start a branch.
Use full training state to resume a run or start a branch where the backend supports it.

SIZE is what the snapshot holds in the bucket: the artifacts ARTIFACTS lists, summed.
It falls when the catalog begins deleting one of them.

EPOCH shows which epoch a save ended, for a run that saves at the end of each epoch.
Each of those saves is registered as a version of the run's model, except the save at the run's last update.
That save is marked "run's model".
Its adapter is the model the run itself registers.

HELD BY identifies what retains a snapshot and prevents it from being deleted.
The holders are a running branch, a candidate registration copying its weights, an operator pin, and the run itself for the weights it saved at the end of an epoch.
An artifact kind with no holder is subject to the catalog's retention limits and may be pruned.

Use "training snapshots get" to inspect one snapshot's manifests, producer, and model shape, and "training snapshots pin" to retain one the catalog would otherwise sweep.

[source,shell]
----
akka optimize training runs snapshots RUN [flags]
----

== Examples

[source,shell]
----
  # List the snapshots a run committed
  akka optimize training runs snapshots 7d496e82c3a15f04

  # Extract the snapshot IDs using jq
  akka optimize training runs snapshots 7d496e82c3a15f04 --jq '.snapshots[].snapshotId'
----

== Options

[source,text]
----
  -h, --help         help for snapshots
      --limit int    Maximum number of entries to return. The service defaults to 50 and allows at most 100
      --offset int   Index of the first entry to return
----
