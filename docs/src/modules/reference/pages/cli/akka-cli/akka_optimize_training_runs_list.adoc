= akka optimize training runs list

List training runs

== Synopsis

List training runs, including runs executed by pipeline stages.

Use --phase open to list active and incomplete runs.
You can also filter by specific phase names, such as --phase COMPLETED or --phase TRAINING.
Use --project to list one training project's runs, named by its name or ID.

A row of an archived training project is left out unless --archived is given or --project names that project.
Such a row is marked "(archived)".

[source,shell]
----
akka optimize training runs list [flags]
----

== Examples

[source,shell]
----
  # List all training runs
  akka optimize training runs list

  # List active and incomplete runs
  akka optimize training runs list --phase open

  # List one project's unfinished runs
  akka optimize training runs list --project router --phase open

  # Output specific fields as JSON
  akka optimize training runs list --json runId,phase,projectId

  # Filter failed runs using jq
  akka optimize training runs list --jq '.runs[] | select(.phase=="FAILED") | .runId'
----

== Options

[source,text]
----
      --archived         Include the runs of archived training projects
  -h, --help             help for list
      --phase string     Filter by phase. Pass 'open' to list unfinished entries
      --project string   List only this training project's runs, by name or ID
----
