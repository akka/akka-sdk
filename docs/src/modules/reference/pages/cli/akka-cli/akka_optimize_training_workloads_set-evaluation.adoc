= akka optimize training workloads set-evaluation

Set evaluation dataset and grader for a workload

== Synopsis

Configure the evaluation dataset and grader used to compare candidate models for a workload.

Score comparisons require matching dataset and grader pairs.
Updating either value resets the default baseline comparison table.
Previous evaluation scores remain accessible by supplying --dataset and --grader to the "scores" command.

----
akka optimize training workloads set-evaluation WORKLOAD --dataset HASH [flags]
----

== Examples

----
  # Set the evaluation dataset
  akka-optimize training workloads set-evaluation commit-router --dataset eval-set

  # Set both evaluation dataset and grader
  akka-optimize training workloads set-evaluation commit-router \
    --dataset 4b1c2f9b2ae4 --grader model:commit-judge
----

== Options

----
      --dataset string   Evaluation dataset name or hash
      --grader string    Grader specification: json-label-match, model:MODEL, or http:URL
  -h, --help             help for set-evaluation
----
