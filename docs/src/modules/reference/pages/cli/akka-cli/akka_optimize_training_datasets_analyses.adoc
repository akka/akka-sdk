= akka optimize training datasets analyses

List a dataset version's analyses, newest first, without starting one

== Synopsis

List the analyses of a dataset version, newest first, each as its last attempt.
The command starts no analysis.

DATASET is a registry reference, resolved as "analyze" resolves it: triage/train for the latest version, triage/train:v3, triage/train:ALIAS or triage/train@sha256:DIGEST.
--model lists only the analyses under one base model, by repository or catalog id.
A base model no longer in the catalog is matched by its repository.

Two dataset versions that hold the same examples share their analyses.
Each analysis is listed under the version it was started for.
The list covers every base model commit and Optimize version the examples were measured under.
ROWS and MAX TOKENS are what a done analysis measured.

--offset and --limit page through a long list.
Where more analyses remain, the command names the --offset of the next page.
The list is read from the newest attempts of the examples, up to a bound, and the command says so where older analyses may be left out.

-o json prints the list as Optimize sends it, with each analysis in full as Optimize answers a read of that analysis.

[source,shell]
----
akka optimize training datasets analyses DATASET [--model BASE_MODEL] [flags]
----

== Examples

[source,shell]
----
  # List the analyses of a dataset's latest version
  akka optimize training datasets analyses triage/train

  # List only those under one base model
  akka optimize training datasets analyses triage/train:v3 --model Qwen/Qwen3-0.6B
----

== Options

[source,text]
----
  -h, --help           help for analyses
      --limit int      Maximum number of entries to return. The service defaults to 50 and allows at most 100
      --model string   Only the analyses under this base model, by repository or catalog id
      --offset int     Index of the first entry to return
----
