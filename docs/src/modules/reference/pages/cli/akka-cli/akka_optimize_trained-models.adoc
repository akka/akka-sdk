= akka optimize trained-models

Manage trained models and baselines

== Synopsis

Manage trained models, baseline models, and external adapters.

Models record their associated workload, training run provenance, base model lineage, and serving configuration.

You can register base models or externally trained adapters to establish baselines for evaluation.
Model governance and deployment are managed under the `models` command group.

== Examples

----
  # List models for a workload
  akka-optimize trained-models list --workload router

  # Display details for a model
  akka-optimize trained-models get 4f3a91c07b2e5d68
----
