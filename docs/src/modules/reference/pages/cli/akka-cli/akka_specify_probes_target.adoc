= akka specify probes target

Declare a running instance as a copy or as production, or list the declared ones.

== Synopsis

Records that probes may contact a running instance of the system, and what it is.
A probe that changes state (sequence, ordering, concurrency, distribution, clock, adverse) runs only against a target declared a copy.
Against production only probes that read run.
A target nobody declared is not contacted.

The address is stored without credentials, query or fragment.
With no argument the declared targets are listed.

[source,shell]
----
akka specify probes target [url] [flags]
----

== Options

[source,text]
----
      --dir string    project directory (default: current)
  -h, --help          help for target
      --kind string   copy or production
----
