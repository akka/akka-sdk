= akka optimize training projects history

Display change history for a training project

== Synopsis

Display the chronological audit history of changes to a training project.

The history records evaluation setting updates and description edits.

[source,shell]
----
akka optimize training projects history PROJECT [flags]
----

== Examples

[source,shell]
----
  # View audit history for a training project
  akka optimize training projects history commit-router
----

== Options

----
