= akka optimize training runs compare

Compare a supervised run's training loss with a baseline, step by step

== Synopsis

Compare the training loss of a supervised run with a baseline over windows of steps.

The command accepts only supervised runs.
Reinforcement runs record a reward at each step instead of a training loss.

Runs with the same plan and seed train the same rows at every step.
A difference in their loss at a step therefore comes from what they learned, not from which rows they drew.
The command calculates the mean loss difference for windows of --window steps.
It reports a gradient spike when either run's gradient norm before clipping is at least --spike-factor times that run's median.
It also reports the first full window whose mean difference, in either direction, is greater than --margin.

The backward pass is nondeterministic, so two runs with the same plan can differ.
A gradient spike can affect one run's loss for many steps.
Interpret a parting window by comparing it with repeated runs of the same plan.

By default, the command rejects runs with different plans, in dataset, seed, base model, sequences per update or any other setting of the configuration.
The loss of such runs differs because of their plans, as well as because of what they learned.
Use --across-plans to compare them and report the plan differences.
Two runs that differ only in how they divide the same sequences per update across devices, passes, and accumulation train on the same rows.
The command compares these runs and reports the division.

[source,shell]
----
akka optimize training runs compare RUN BASELINE [flags]
----

== Examples

[source,shell]
----
  # Compare a run with a baseline that uses the same plan
  akka optimize training runs compare 7d496e82c3a15f04 be2a310245ea0c11

  # Wider windows and a stricter margin
  akka optimize training runs compare 7d496e82c3a15f04 be2a310245ea0c11 \
    --window 20 --margin 0.02

  # The first window where the two part, if any
  akka optimize training runs compare 7d496e82c3a15f04 be2a310245ea0c11 \
    --jq .parting
----

== Options

[source,text]
----
      --across-plans         Compare runs with different plans and report the differences
  -h, --help                 help for compare
      --margin float         Mean loss difference over a full window, in either direction, above which the runs part (default 0.03)
      --spike-factor float   Minimum multiple of the run's median gradient norm that counts as a spike (default 10)
      --window int           Number of steps averaged into each row (default 10)
----
