= akka optimize training runs wait

Wait for a training run to finish

== Synopsis

Stream status updates for a training run until it reaches a terminal phase.

By default, the command exits with code 0 upon reaching COMPLETED, FAILED, or CANCELLED.
Use --exit-status to return a non-zero exit code if the run ends in FAILED or CANCELLED, or if a smoke check fails.

Use --timeout to set a maximum wait duration.
If the timeout expires, the command exits with a non-zero status while the run continues in the background.

Interrupting with Ctrl-C stops following the run without cancelling it.

A dropped stream is reopened rather than reported, and so is a gateway that answers while it has nothing to reach: the wait retries eight times in a row over about two minutes, backing off between attempts.
Past that it reports what it could not reach and exits.
The run is unaffected either way, and another "wait" reconnects to it.

When using -o json, updates are streamed to stdout as line-delimited JSON events, ending with a terminal event that includes the failure reason and any smoke verdict.
The full run record follows the terminal event, pretty-printed.
Use -o json-compact to keep the record on one line when a script reads the output line by line.

----
akka optimize training runs wait RUN [flags]
----

== Examples

----
  # Wait for a run to finish
  akka-optimize training runs wait 7d496e82c3a15f04

  # Wait up to 2 hours and exit with non-zero status if the run fails
  akka-optimize training runs wait 7d496e82c3a15f04 --timeout 2h --exit-status

  # Suppress intermediate progress updates
  akka-optimize training runs wait 7d496e82c3a15f04 -q

  # Stream updates as JSON
  akka-optimize training runs wait 7d496e82c3a15f04 -o json | jq -c .
----

== Options

----
