= akka optimize training projects archive

Archive a training project

== Synopsis

Archive a training project, which leaves it and its runs, evaluations, endpoints and distillations out of the listings and refuses new work for it.

Archiving is refused while the project has work in progress: a run that has not finished, a paused one included, an endpoint that is starting or serving, an open evaluation or distillation, or an open pipeline with a stage in the project.
The refusal names each item.

An archived project still answers "get", and its models can still be referenced.
Archiving the project does not archive its registry namespace.
Where the namespace is not archived, the command says so and names the command that archives it.

[source,shell]
----
akka optimize training projects archive PROJECT [flags]
----

== Examples

[source,shell]
----
  # Archive a training project
  akka optimize training projects archive commit-router
----
