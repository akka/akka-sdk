= akka local services stop

Stop one service that 'akka local services run' started.

== Synopsis

The `akka local services stop` command stops the service named NAME, its pom.xml's artifactId, that `akka local services run` or the akka_local_run_service MCP tool started.
The local runtime and every other service keep running.
When the local runtime is not running, the command fails.

[source,shell]
----
akka local services stop NAME [flags]
----

== Examples

[source,shell]
----
akka local services stop shopping-cart
----
