= akka optimize training base-models

See which base models this deployment allows, and select one to use

== Synopsis

The allowed list is what an operator permits and this deployment's hardware can hold, so a model that is listed is one you can use.
A model the hardware cannot hold is not listed at all.

A base model is named by the repository the listing shows.
An entry id or the model id a run names resolves too, for a script that stored one.

Listing and selecting hold no GPU.
Selecting registers the model and fetches its weights into the cluster's cache, which is the only wait in this area and is paid once per model per deployment.
Runs, evaluations and endpoints may name a model the moment it is selected;
work queued behind one that is still preparing waits for the weights rather than being refused.

== Examples

----
  # See what you can use
  akka-optimize training base-models list

  # Select a model by the repository the listing shows
  akka-optimize training base-models select Qwen/Qwen3-8B

  # Watch how far preparing it has got
  akka-optimize training base-models get Qwen/Qwen3-8B

  # Or wait for one that is already being prepared
  akka-optimize training base-models wait Qwen/Qwen3-8B
----
