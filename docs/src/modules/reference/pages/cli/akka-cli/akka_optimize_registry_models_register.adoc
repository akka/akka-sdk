= akka optimize registry models register

Register a base model, an adapter or model weights under a named model

== Synopsis

Register a model version from a JSON or YAML descriptor.

 { "servingModel": { "variant": "BASE", "baseModel": "Qwen/Qwen3-0.6B" } }

The variant is BASE, ADAPTER or WEIGHTS:

* BASE:    the repository in baseModel, and an optional revision.
A request with no          revision is pinned to the repository's current head.
* ADAPTER: an explicit registered baseModel version, adapterRank, and artifact ref.
* WEIGHTS: an explicit registered baseModel version and artifact ref.

For trained models, include exactly one model/base lineage parent matching baseModel.
Register the base separately first and reuse its version on retries.
Omit revision on the trained descriptor.

The registry derives the version's digest from the descriptor and the artifact record, so registering an identical descriptor returns the version that is already there and appends nothing.
--alias points an alias at the result in the same request.

The named model and its namespace are created by the first registration into them.

----
akka optimize registry models register NS/NAME -f FILE [flags]
----

== Examples

----
  # Register a base model to score as a baseline
  akka-optimize registry models register qwen/qwen3-0.6b -f base-model.json

  # Register a trained adapter and point an alias at it
  akka-optimize registry models register triage/classifier -f adapter.json --alias candidate

  # Keep the reference the registration returned
  REF="$(akka-optimize registry models register triage/classifier -f adapter.json --jq .reference)"
----

== Options

----
      --alias string   Point this alias of the named model at the registered version
  -f, --file string    Path to the model descriptor file. Use '-' to read from standard input
  -h, --help           help for register
----
