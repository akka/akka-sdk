= akka services ledger records get

Get one ledger record.

== Synopsis

The `akka services ledger records get` command shows one ledger record: the metadata every record carries, such as its type, component and references, and the fields of its type.

A record that refers to an interaction is shown with the part of that interaction it is about: the messages an evaluation judged, the message or tool call a guardrail decided on, or the result of a tool call intent.
With `--with-records` an evaluation record is followed by every record produced during the evaluation, such as the interactions of a judge agent, newest first.

Use `-o json` for the full records.

[source,shell]
----
akka services ledger records get SERVICE_NAME RECORD_ID [flags]
----

== Options

[source,text]
----
  -h, --help             help for get
      --owner string     the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string   project to use if not using the default configured project
      --region string    region to use if project has more than one region
      --with-records     Also list the records produced during the evaluation. Applies to evaluation records only.
----
