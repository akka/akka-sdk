= akka eval campaigns replay

Re-run one campaign or item deterministically from its manifest.

== Synopsis

Replays a finished campaign from its recorded manifest.

----
akka eval campaigns replay ID [flags]
----

== Options

----
      --item string             replay only this item
      --target-override string  send prompts to this URL
  -h, --help                    help for replay
----
