= akka optimize training endpoints detach

Stop serving one model at an endpoint

== Synopsis

Stop serving one model, leaving the endpoint up for whatever else is attached to it.
ENDPOINT takes an ID or an unambiguous prefix of it.

MODEL may be the displayed model name (including a shortened adapter), the model ID, or an unambiguous prefix of the ID.

Detaching the last model takes the endpoint down, so a caller that detaches what it attached releases the devices it was responsible for and nothing else.

Refused for the judge a run is still calling, naming that run.
Anything else at the same endpoint detaches as usual.

----
akka optimize training endpoints detach ENDPOINT MODEL [flags]
----

== Examples

----
  # Stop serving one candidate
  akka-optimize training endpoints detach 970076e8 triage-candidate
----
