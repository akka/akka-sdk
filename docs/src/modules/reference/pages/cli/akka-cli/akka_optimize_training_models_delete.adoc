= akka optimize training models delete

Deprecate an imported model's version and remove its files in 30 days

== Synopsis

Delete a merged model that "training models import" placed.
Its registry version is deprecated now, and its files are removed from the bucket in 30 days.
The command prints the time they are removed.
Deleting the same version again answers the removal already scheduled.
You need permission to delete models in the serving project the import named.

A KalixModel that still names the model keeps serving until its files are removed, and after that fails on any node that has to fetch it again.
Delete or repoint such a KalixModel before then.

The command asks you to type the reference back.
--force deletes without asking.

[source,shell]
----
akka optimize training models delete NS/NAME:VERSION [flags]
----

== Examples

[source,shell]
----
  # Delete an imported model version
  akka optimize training models delete triage/support-merged:v1

  # Delete without the prompt
  akka optimize training models delete triage/support-merged:v1 --force
----
