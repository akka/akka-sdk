= akka optimize training distillations rejections

Display the rejected answers of a distillation

== Synopsis

Display each rejected answer's audit record from saved chunks, in source order.
Each record shows the decision, rejection reason and how the teacher stopped.

With -o json, each record is printed unchanged, with one JSON object per line.
Records are available while the distillation is in progress.

[source,shell]
----
akka optimize training distillations rejections DISTILLATION [flags]
----

== Examples

[source,shell]
----
  # Display the first 20 rejected answers
  akka optimize training distillations rejections 4b1f0c2e9a7d --limit 20

  # Write every record as JSON lines
  akka optimize training distillations rejections 4b1f0c2e9a7d -o json > rejections.jsonl
----

== Options

[source,text]
----
  -h, --help        help for rejections
      --limit int   Limit output to the first N rejected answers
