= akka organizations role-bindings

Manage organization role bindings.

== Synopsis

The `akka organizations role-bindings` commands manage the role bindings of an organization.
A role binding grants a role in the organization, either one of the built in roles or one of the organization's custom roles (see `akka organizations roles`), to a principal.
Principals include users, groups, Akka services and workload identities, so the role bindings of an organization are not just its users.
To view users with pending invitations run `akka organizations invitations list`.

For more details, see https://doc.akka.io/operations/security/organization-role-bindings.html .
