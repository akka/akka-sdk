= akka optimize training endpoints wait

Wait for an endpoint to answer

== Synopsis

Wait until an endpoint answers, reporting what it is waiting for as it goes.

ENDPOINT takes an ID or an unambiguous prefix of it.

An endpoint that will not answer ends the wait as a failure, because a model that is not answerable is not what was asked for.
That is the same outcome "endpoints create --wait" gives, and it differs from waiting on a run, which reports a failed run without failing itself unless --exit-status says to.

Ctrl-C stops watching.
The endpoint carries on coming up and keeps whatever devices it was granted, so stopping the wait is not a way to take it down.

--timeout bounds the wait and leaves the endpoint alone when it expires.
It defaults to the same deadline "endpoints create --wait" uses, and zero waits without one.

----
akka optimize training endpoints wait ENDPOINT [flags]
----

== Examples

----
  # Wait for an endpoint to answer
  akka-optimize training endpoints wait 970076e8

  # Give up watching after ten minutes
  akka-optimize training endpoints wait 970076e8 --timeout 10m

  # Wait without a deadline
  akka-optimize training endpoints wait 970076e8 --timeout 0
----

== Options

----
  -h, --help               help for wait
      --timeout duration   Maximum time to wait for the endpoint; zero waits without a deadline (default 15m0s)
----
