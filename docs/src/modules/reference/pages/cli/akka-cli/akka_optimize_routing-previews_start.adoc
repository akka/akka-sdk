= akka optimize routing-previews start

Preview a draft of one ruleset over recorded traffic

== Synopsis

Start a preview of a draft of one ruleset over a period, and print the run.

The draft is a ruleset document as `rulesets apply -f` reads it, for a ruleset in force or a new one.
The period is by when the gateway shipped each capture: --from inclusive, --to exclusive.
--to defaults to a minute before now, which leaves room for a clock ahead of the service's, and --from to 24 hours before --to.

--sample-percent reads that percent of the period's exchanges, chosen by exchange id, so two previews of the same period at the same percent read the same exchanges.

[source,shell]
----
akka optimize routing-previews start --ruleset NAME --draft FILE [flags]
----

== Examples

[source,shell]
----
  akka optimize routing-previews start --ruleset optimize --draft optimize.yaml --watch
  akka optimize routing-previews start --ruleset optimize --draft optimize.yaml \
      --from 2026-11-16T09:00:00Z --to 2026-11-17T09:00:00Z --sample-percent 10
----

== Options

[source,text]
----
      --draft string           the draft ruleset document; - reads stdin
      --from string            start of the period, an RFC 3339 instant, inclusive; 24 hours before --to by default
  -h, --help                   help for start
      --ruleset string         the ruleset the draft is for
      --sample-percent float   the percent of the period's exchanges to read, more than 0 and at most 100 (default 100)
      --to string              end of the period, an RFC 3339 instant, exclusive; a minute before now by default
      --watch                  read the preview every 2 seconds until it ends, then print it
----
