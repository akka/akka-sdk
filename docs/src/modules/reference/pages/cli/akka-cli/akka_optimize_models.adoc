= akka optimize models

Models in the registry, with what training, routing and pricing know about them

== Synopsis

A model is a version in the registry.
A read adds what the services that own each fact know about it: the trainer's run, evaluations and endpoints, the gateway router's destinations, rules and manifest, and the price portfolio holds for its served names.

The registry must answer.
A part whose service does not answer within 10s, or within --timeout where you state one, is shown as unavailable, and the read still succeeds.

Register a model version and move its aliases with `registry models`.
