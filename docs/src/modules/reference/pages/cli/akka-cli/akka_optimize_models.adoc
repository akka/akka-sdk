= akka optimize models

The corporate model registry

== Synopsis

Every model the organization uses, whatever its origin.

The registry is an index, not a store: an entry points at where a model resides and carries the governance around it.
Retiring an entry ends the sanction to use the model;
it does not touch the weights.
