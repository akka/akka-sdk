= akka specify idea next

Say whether a station command goes on to the idea's next station on its own.

== Synopsis

[Incubating] Answer whether the station command that just closed its run goes on into the next station's command in its own session, and why.
It goes on only outside Enforced mode, for an idea that continues, once the station is done, and while nothing waits on a person: no open run or wait, no spending limit reached, the next station neither stale, blocked nor Ship.
A command the console started (AKKA_RUN_ID set) does not go on: the console starts the next station.
The idea is --idea, else the one a branch named for it is on.
--from names the station the command just ran, which may be behind the idea's station: the answer is then about the station after it, not the station after the idea's.

[source,shell]
----
akka specify idea next [flags]
----

== Options

[source,text]
----
      --dir string    project directory (default: current)
      --from string   the station the command just ran (default: the idea's station)
  -h, --help          help for next
      --idea string   the idea (default: the one a branch named for it is on)
      --json          print {go, next, reason}
----
