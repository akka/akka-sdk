= akka optimize training runs resume

Resume a paused training run

== Synopsis

Resume a paused training run from its last completed checkpoint.

With --step, resume from the run's save at that step instead.
The save has to still hold its training state: execution.keepRecoverable sets how many of the newest saves keep it.
The updates after that step are trained again.

Associated evaluation judges are restarted and reconnected automatically.
The run retains its existing ID, metric history, and checkpoint records.

[source,shell]
----
akka optimize training runs resume RUN [flags]
----

== Examples

[source,shell]
----
  # Resume execution of a paused training run
  akka optimize training runs resume 7d496e82c3a15f04

  # Resume from the save at step 100
  akka optimize training runs resume 7d496e82c3a15f04 --step 100
----

== Options

[source,text]
----
  -h, --help       help for resume
      --step int   resume from the run's save at this step rather than its newest
----
