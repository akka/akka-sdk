= akka optimize training runs resume

Resume a paused training run

== Synopsis

Resume a paused training run from its last completed checkpoint.

Associated evaluation judges are restarted and reconnected automatically.
The run retains its existing ID, metric history, and checkpoint records.

----
akka optimize training runs resume RUN [flags]
----

== Examples

----
  # Resume execution of a paused training run
  akka-optimize training runs resume 7d496e82c3a15f04
----
