= akka specify run thread end

End a research thread done, or failed with one sentence.

== Synopsis

[Incubating] Records the action under the idea's lock and prints the thread as JSON.
--run names an open station run;
--agent is agent-+++<positive number="">+++.
Start takes a one-line --title and returns the thread's id, TH-+++<n>+++.
End takes that --thread and --outcome done, or failed with a one-sentence --text.
A thread is ended once, by the agent that started it.
A console command may touch only its own run.+++</n>++++++</positive>+++

[source,shell]
----
akka specify run thread end [flags]
----

== Options

[source,text]
----
      --agent string     agent id, such as agent-1
      --dir string       project directory (default: current)
  -h, --help             help for end
      --json             print JSON (thread actions always print JSON)
      --outcome string   done or failed
      --run string       open run id (default: AKKA_RUN_ID)
      --text string      for failed, one sentence saying why
      --thread string    thread id that start printed, such as TH-1
----
