= akka specify fixtures replay

Send a set's requests to the rebuild and report which answers differ.

== Synopsis

Rebuilds every request in the set and sends it to the address given.
The status and the body are compared with the recorded answer under the same redaction as the recording;
a set recorded from production holds no bodies and is compared by status and body shape.

Requests go only to an address on this machine or one declared a copy with 'probes target'.
An address declared production is refused.
The command exits non-zero when any answer differs.

[source,shell]
----
akka specify fixtures replay <set> --against <url> [flags]
----

== Examples

[source,shell]
----
  akka specify fixtures replay orders --against http://localhost:9100
----

== Options

[source,text]
----
      --against string   address of the rebuild
      --dir string       project directory (default: current)
  -h, --help             help for replay
----
