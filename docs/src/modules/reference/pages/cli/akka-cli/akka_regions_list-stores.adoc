= akka regions list-stores

List the Postgres store clusters available in each region.

== Synopsis

The `akka regions list-stores` command lists the Postgres store clusters configured in each region.
An assignable store may be passed to `akka project new --store` or set in a project descriptor (when store selection is enabled for your organization);
otherwise the platform resolves one automatically.

Optional `--organization` limits the listing to a single organization's regions, and `--region` to a single region.

----
akka regions list-stores [flags]
----

== Options

----
  -h, --help                  help for list-stores
      --organization string   list stores for regions in this organization
      --region string         only list stores for this region
----
