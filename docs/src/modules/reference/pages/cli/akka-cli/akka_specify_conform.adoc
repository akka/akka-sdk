= akka specify conform

Evaluate exit conditions and report the engine verdict.

== Synopsis

[Incubating] Evaluate the resolved exit conditions against the project (running the available auditors), print the Definition-of-Done manifest, then report the engine verdict -- one of NEEDS_INPUT / WORKING / READY_TO_SHIP.

Exits non-zero unless the verdict is READY_TO_SHIP, so it can gate CI or ship.

Examples:   akka specify conform   akka specify conform --policy ./policy.yaml

----
akka specify conform [directory] [flags]
----
