= akka optimize registry datasets

Named datasets, their versions and their aliases

== Synopsis

A dataset version is a fixed set of objects in one format, with a digest derived from the object listing.
Uploading the same objects under the same name returns the version that is already there, and changing the examples appends a version.

A reference is one string: NS/NAME for the named artifact, NS/NAME:v2 for a version, NS/NAME:serving for the version an alias points at, and NS/NAME@sha256:...
for a version by digest.
NS/NAME where a version is wanted is the newest version.

== Examples

----
  # Upload examples and point an alias at the version
  akka-optimize registry datasets register triage/train -f examples.jsonl --alias candidate

  # Read the named dataset
  akka-optimize registry datasets get triage/train

  # Read the version an alias points at
  akka-optimize registry datasets get triage/train:candidate
----
