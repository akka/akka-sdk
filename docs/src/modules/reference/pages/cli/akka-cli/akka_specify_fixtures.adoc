= akka specify fixtures

[Incubating] Replay a recorded fixture set against a rebuild, or freeze it.

== Synopsis

[Incubating] A fixture set is what 'probes run' recorded from the original: each request with the answer it got, kept redacted.
'replay' sends the requests to the rebuild and reports where its answers differ.
'freeze' fixes a set so it can stand in for the original once the original is gone.
