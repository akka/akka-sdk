= akka eval datasets items

The items in one version of a dataset.

== Synopsis

Lists the scenarios inside a specific dataset version.

----
akka eval datasets items ID --version V [flags]
----

== Options

----
      --version string   the dataset version to read
  -h, --help             help for items
----
