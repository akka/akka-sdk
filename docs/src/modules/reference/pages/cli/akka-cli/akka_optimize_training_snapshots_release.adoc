= akka optimize training snapshots release

Release a reference left behind by its owner

== Synopsis

Release a reference whose owner no longer needs it.

A child run releases its source when it ends.
A candidate registration releases the weights once its own copy is durable.
Either can stop without releasing its reference.
Run cleanup may fail to reach the catalog, or a registration may exhaust its release retries.
The reference then retains an artifact that nothing reads.
A run does not automatically release its hold on weights saved at the end of an epoch.
Release that hold here once the run has finished.
Those weights then become subject to the run's retention limits.

Specify OWNER as the complete ID or an unambiguous prefix of the run or model reported under HELD BY by "training runs snapshots".
Every artifact kind that owner retains is released unless you specify one with --kind.

The service verifies the owner.
A run that has not reached a terminal phase retains what it holds, including its epoch weights.
A registration that is still copying also retains what it holds.
A paused run has not reached a terminal phase because resuming reads its source again.
An owner the service cannot find also retains what it holds.
A branch submission retains the source before it starts the child, so an OWNER that resolves to no run may name a child that is still being started.

[source,shell]
----
akka optimize training snapshots release SNAPSHOT OWNER [flags]
----

== Examples

[source,shell]
----
  # Release what a cancelled child run never gave back
  akka optimize training snapshots release 3f2a9c71bd04 7d496e82c3a1
----
