= akka optimize training snapshots release

Release a reference left behind by its owner

== Synopsis

Release a reference whose owner no longer needs it.

A child run releases its source when it ends, and a candidate registration releases the weights once its own copy of them is durable.
Either can stop without doing so: a run whose cleanup could not reach the catalog, or a registration whose release exhausted its retries.
The reference then keeps an artifact alive that nothing reads.

OWNER is the run or model reported under HELD BY by "training runs snapshots", specified as a complete ID or an unambiguous prefix.
Every kind that owner retains is released unless --kind specifies one.

The service verifies the owner rather than accepting the request at face value.
A run that has not reached a terminal phase, and a registration that is still copying, retain what they hold.
A paused run has not reached a terminal phase, because resuming reads its source again.
An owner the service cannot find retains what it holds too: a branch submission retains the source before it starts the child, so an OWNER that resolves to no run may name a child that is still being started.

----
akka optimize training snapshots release SNAPSHOT OWNER [flags]
----

== Examples

----
  # Release what a cancelled child run never gave back
  akka-optimize training snapshots release 3f2a9c71bd04 7d496e82c3a1
----
