= akka optimize models list

Every model version, and the served names no version accounts for

== Synopsis

List every model version the registry holds, one row each.

Then list the served names that are priced in the pricing catalog in force, or that portfolio recorded traffic to in the last 30 days, and that no version accounts for: no hosted version is served under the name, and no endpoint answers under it.
Register one with `registry models register` to bring it into the directory.

The versions of an archived namespace are listed with --archived.
They account for their served names either way, as do the endpoints of archived training projects.

--namespace lists the versions of one namespace, archived or not, and no unregistered served names, which belong to no namespace.
--lifecycle keeps the rows in one lifecycle.

[source,shell]
----
akka optimize models list [flags]
----

== Examples

[source,shell]
----
  # List every model version and the unregistered served names
  akka optimize models list

  # List the retired versions of one namespace
  akka optimize models list --namespace triage --lifecycle retired
----

== Options

[source,text]
----
      --archived           Include the versions of archived namespaces
  -h, --help               help for list
      --lifecycle string   List the versions in one lifecycle: active, deprecated or retired
      --namespace string   List the versions of one namespace
----
