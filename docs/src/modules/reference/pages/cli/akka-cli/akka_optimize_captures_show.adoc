= akka optimize captures show

One capture, raw or normalized, read forward

== Synopsis

One capture, from a raw capture or a normalized record, gzip-compressed or not.
What the file is is decided by its content, not its name.

The head line and the decision lines read the same in both forms.
Below them, a raw capture renders as a reader walks it: frames, rule executions and classifier calls in the order they happened, each with its offset from the start of the exchange.
A normalized record has no frames: it renders its classifier calls at their offsets, one line per fact the record states, and the input and the output in full.
-o json carries the whole record.

Rendered in order rather than summarised.
A rule's position among the message frames is its position in time, and so is a classifier call's, which is what says whether a decision depended on an answer or preceded it.

[source,shell]
----
akka optimize captures show FILE [flags]
----
