= akka local services components entities delete-snapshot

Delete the stored state snapshot of a single entity instance.

== Synopsis

The `akka local service components entities delete-snapshot` command deletes the stored state snapshot of a single entity instance, so that its state is rebuilt by replaying the full event log.
Use it for state schema evolution, when an existing snapshot holds a state the component can no longer deserialize.
Deleting the snapshot also stops (or restarts for workflow) the running instance, so it drops the state it had recovered from that snapshot.

A snapshot change applies only in the region it is sent to.
In a project with more than one region, pass --all-regions to run in every region, or --region REGION to run in one.
A single-region project needs neither.

----
akka local services components entities delete-snapshot SERVICE_NAME COMPONENT_ID ENTITY_ID [flags]
----

== Options

----
      --all-regions      run the command in every region of the project
  -f, --force            Skip the confirmation prompt.
  -h, --help             help for delete-snapshot
      --owner string     the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string   project to use if not using the default configured project
      --region string    region to use if project has more than one region
----
