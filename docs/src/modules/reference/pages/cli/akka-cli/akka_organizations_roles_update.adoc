= akka organizations roles update

Update a custom role of the organization from a YAML descriptor.

== Synopsis

Update the custom role identified by the id field of the YAML descriptor.
The whole role is replaced by the descriptor, partial updates are not supported.

[source,shell]
----
akka organizations roles update [flags]
----

== Examples

[source,shell]
----
akka organizations roles update -f my-role.yaml
----

== Options

[source,text]
----
  -f, --file string           The YAML descriptor file. If not supplied, will read from stdin.
  -h, --help                  help for update
      --organization string   name or ID for organization
----
