= akka optimize training runs start

Start a training run from a plan file

== Synopsis

Start a training run from a JSON or YAML plan file.

The plan descriptor specifies the workload, base model, and config:

 { "kind": "run", "workload": "...", "baseModel": "...", "config": { "dataset": "..." } }

The dataset must already be registered by hash or name using "datasets create".

Each submission provisions compute resources and initiates a new training run.
Submitting an existing plan starts an additional run with that configuration.
Confirmation is requested before starting the run unless --force is specified.
The plan is validated against the service before confirmation is requested, and with --dry-run.
When no confirmation is requested, the service validates the plan on the start request itself.

--show-resolved, with --dry-run, prints the config and execution a submission of this plan would train under, every default filled in.

----
akka optimize training runs start -f PLAN [flags]
----

== Examples

----
  # Start a training run from a plan file
  akka-optimize training runs start -f plan.json

  # Validate the plan without starting a run
  akka-optimize training runs start -f plan.json --dry-run

  # See what a plan resolves to, with every default filled in
  akka-optimize training runs start -f plan.json --dry-run --show-resolved

  # Start a run and wait for completion
  akka-optimize training runs start -f plan.json --wait --exit-status

  # Submit a plan from standard input
  cat plan.json | akka-optimize training runs start -f -
----

== Options

----
      --dry-run         Validate the plan against the service without starting anything
      --exit-status     Exit with a non-zero status if execution fails or is cancelled. Requires --wait
  -f, --file string     Path to the plan file. Use '-' to read from standard input
  -h, --help            help for start
      --show-resolved   With --dry-run, also display the config and execution the plan resolves to
      --wait            Wait for execution to finish
----
