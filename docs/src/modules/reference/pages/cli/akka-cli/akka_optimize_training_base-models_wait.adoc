= akka optimize training base-models wait

Wait for a base model to finish being prepared

== Synopsis

Wait until an entry is admitted and its selection has settled.

BASE_MODEL takes the repository, the entry ID, the model ID a run names, or an unambiguous prefix of either ID.

The wait ends once the selection reads READY, which it reaches whether the weights were cached or not: a model whose weights could not be warmed is still usable and its first job pays the download.
What actually happened is in the record this prints, under Weights.

An entry admission refused, and an entry nobody has selected, both end the wait as a failure.
Neither is being prepared, so waiting on either would never finish.

Ctrl-C stops watching.
Preparation continues in the cluster.

--timeout bounds the wait.
By default there is no deadline.

----
akka optimize training base-models wait BASE_MODEL [flags]
----

== Examples

----
  # Wait for a selection to settle
  akka-optimize training base-models wait Qwen/Qwen3-8B

  # Give up watching after ten minutes
  akka-optimize training base-models wait Qwen/Qwen3-8B --timeout 10m
----

== Options

----
  -h, --help               help for wait
      --timeout duration   Maximum time to wait for the entry; zero waits without a deadline
----
