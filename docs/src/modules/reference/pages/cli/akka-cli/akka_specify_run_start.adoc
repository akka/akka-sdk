= akka specify run start

Open a run of a station command and write the visit's receipt.

== Synopsis

[Incubating] Open a run of a station command in an idea's record.
The idea is --idea, else the one a branch named for it is on;
in Enforced mode pass --idea.
A command the console started joins the run the console opened for it, named in AKKA_RUN_ID, and is refused any other run;
it may leave out --station and --command, which the console chose.
Elsewhere --station and --command are required.
When no idea matches the branch, the run is not recorded and the command continues;
in Enforced mode it is refused, and the project's ideas are adopted first.
In Enforced mode an idea named that does not exist, or a branch that matches more than one idea, is refused as idea-unresolved.
Refused, with what to do instead, when the idea is paused, shipped or dropped, and, in Enforced mode, when the spec or tasks approval the station needs is missing or a station before it is not done.
In à la carte mode a missing approval is recorded as bypassed and the run opens.
With --json a refusal by rule is printed as {refused, message, remedy}, refused naming the rule.

[source,shell]
----
akka specify run start [flags]
----

== Options

[source,text]
----
      --args string      the command's arguments
      --command string   the station command, such as /akka:plan
      --dir string       project directory (default: current)
      --harness string   the coding agent running the command, such as claude-code
  -h, --help             help for start
      --idea string      the idea (default: the one a branch named for it is on)
      --json             print the run as JSON
      --policy string    path to an org governance policy-as-code file (policy.yaml)
      --station string   the station: discover, specify, clarify, plan, tasks, implement, review, conform or ship
      --task string      the task the run starts on
      --where string     where the run is: laptop or console (default "laptop")
----
