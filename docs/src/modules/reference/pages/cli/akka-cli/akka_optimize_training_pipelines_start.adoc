= akka optimize training pipelines start

Start a training pipeline from a plan file

== Synopsis

Start a training pipeline from a JSON or YAML plan file.

The plan descriptor defines the ordered stages of the pipeline:

 { "kind": "pipeline", "stages": [ ... ] }

Stages can reference existing datasets by name or hash, or reference outputs from earlier stages using "@stageName".

Each submission provisions compute resources and initiates a new pipeline.
Confirmation is requested before starting the pipeline unless --force is specified.

--show-resolved, with --dry-run, also prints each train stage's config and execution with every default filled in, for a stage whose dataset is already registered.

----
akka optimize training pipelines start -f PLAN [flags]
----

== Examples

----
  # Start a pipeline from a plan file
  akka-optimize training pipelines start -f pipeline.json

  # Start a pipeline and wait for completion
  akka-optimize training pipelines start -f pipeline.json --wait --exit-status

  # Validate the plan against the service without starting anything
  akka-optimize training pipelines start -f pipeline.json --dry-run

  # See what each train stage resolves to, with every default filled in
  akka-optimize training pipelines start -f pipeline.json --dry-run --show-resolved
----

== Options

----
      --dry-run         Validate the plan against the service without starting anything
      --exit-status     Exit with a non-zero status if execution fails or is cancelled. Requires --wait
  -f, --file string     Path to the plan file. Use '-' to read from standard input
  -h, --help            help for start
      --show-resolved   With --dry-run, also display each train stage's resolved config and execution
      --wait            Wait for execution to finish
----
