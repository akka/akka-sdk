= akka optimize captures list

Every exchange captured in a directory, newest first

== Synopsis

Every exchange captured in a directory, newest first, one row per exchange.

Reads every file named *.acp, *.json, *.acp.gz or *.json.gz, raw or normalized, compressed or not, and decides what each is by its content.
FORM says which of the two forms of an exchange the directory holds: raw, normalized or both.
With both, the row is read from the raw capture.

[source,shell]
----
akka optimize captures list DIRECTORY [flags]
----
