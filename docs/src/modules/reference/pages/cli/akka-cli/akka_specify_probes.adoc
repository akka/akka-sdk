= akka specify probes

[Incubating] List, run, and test the probes that examine a system.

== Synopsis

[Incubating] A probe answers one question about a system a specification is being derived from.
'list' shows which probes can reach the system in front of you and which cannot, with the reason.
'run' executes a selection and records what it found.
'test' runs one probe and prints its raw exchange, for debugging a probe you wrote.

== Options
