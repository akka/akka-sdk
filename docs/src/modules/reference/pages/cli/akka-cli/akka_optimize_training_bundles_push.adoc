= akka optimize training bundles push

Upload a scoring bundle from a directory or a zip

== Synopsis

Upload a scoring bundle.
A directory is archived here, always the same way from the same files;
a zip is sent as it stands.
A bundle the server already holds is not sent again.

The bundle's hash is printed.
Use --name to assign or move a name, so a plan can write the name where a rule or a grader names its bundle and keep it when the code changes.
A run records the hash the name pointed at when it was admitted.

----
akka optimize training bundles push PATH [flags]
----

== Examples

----
  # Upload the scoring code and data in a directory
  akka-optimize training bundles push scoring/

  # Upload it under a name a plan refers to
  akka-optimize training bundles push scoring/ --name gsm8k-scoring

  # Upload a zip built elsewhere
  akka-optimize training bundles push scoring.zip
----

== Options

----
  -h, --help          help for push
      --name string   Assign a name to the bundle, or move the name to it
----
