= akka specify waive

Attach a time-bound waiver to a still-active exit condition.

== Synopsis

[Incubating] A waiver is a modifier on a still-active condition: the condition stays visible with its unmet state, annotated with who/why/expiration.
Waiving a locked floor condition requires the org WaiverPolicy to permit it (and, where required, an approver via --by).

----
akka specify waive <condition-id> [flags]
----

== Options

----
      --by string       who authorized the waiver
      --dir string      project directory (default: current)
  -h, --help            help for waive
      --policy string   path to an org governance policy-as-code file (policy.yaml)
      --reason string   why the condition is waived
      --until string    expiration date (YYYY-MM-DD), or 'indefinite' (default)
----
