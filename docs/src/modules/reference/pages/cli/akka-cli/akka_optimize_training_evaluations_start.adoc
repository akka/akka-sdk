= akka optimize training evaluations start

Start an evaluation for a trained model

== Synopsis

Initiate an evaluation to score a trained model against a dataset.

Each evaluation executes as a distinct job and generates an independent evaluation report.

--workload defaults to the workload the model names.
A candidate carries the workload that trained it, so it needs none, and naming a different one is refused.
A base model belongs to no workload, so scoring one to get a baseline needs --workload to say which workload the score belongs to.

----
akka optimize training evaluations start --model MODEL --dataset HASH [flags]
----

== Examples

----
  # Start an evaluation
  akka-optimize training evaluations start --model 4f3a91c07b2e5d68 \
    --dataset 4b1c2f9b2ae4

  # Start an evaluation with a specific grader
  akka-optimize training evaluations start --model 4f3a91c07b2e5d68 \
    --dataset 4b1c2f9b2ae4 --grader model:commit-judge

  # Score a base model, for a baseline to compare candidates against
  akka-optimize training evaluations start --model 4f3a91c07b2e5d68 \
    --dataset 4b1c2f9b2ae4 --workload support-triage

  # Start an evaluation and wait for completion
  akka-optimize training evaluations start --model 4f3a91c07b2e5d68 \
    --dataset 4b1c2f9b2ae4 --wait --exit-status
----

== Options

----
      --dataset string    Evaluation dataset hash, or a unique prefix of one
      --exit-status       Exit with a non-zero status if execution fails or is cancelled. Requires --wait
      --grader string     Grader specification: json-label-match, model:MODEL, or http:URL
  -h, --help              help for start
      --model string      Model ID to evaluate
      --wait              Wait for execution to finish
      --workload string   Workload name or ID the score belongs to. Defaults to the workload the model names, so only a base model needs it, and it must agree with the model's when given
----
