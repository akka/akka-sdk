= akka optimize registry bundles alias set

Point an alias at a version, or move it to another

== Synopsis

Point an alias at a version of its named artifact, or move the one that is there.

A version the named artifact does not hold is refused, and so is an alias name with the form of a version.

----
akka optimize registry bundles alias set NS/NAME:ALIAS --version vN [flags]
----

== Examples

----
  # Promote a version
  akka-optimize registry bundles alias set triage/classifier:serving --version v2
----

== Options

----
  -h, --help             help for set
      --version string   The version to point the alias at, such as v2
----
