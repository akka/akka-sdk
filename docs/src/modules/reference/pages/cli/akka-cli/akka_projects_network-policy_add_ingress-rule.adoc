= akka projects network-policy add ingress-rule

Add an ingress rule to the network policy for your Akka project.

== Synopsis

The `akka project network-policy add ingress-rule` command adds a rule allowing traffic into the services in your project.
If neither --port nor --from is specified, the rule allows all traffic from all sources.

----
akka projects network-policy add ingress-rule [flags]
----

== Options

----
      --force-global       force an existing regional resource to be configured as a global resource
      --force-regional     force an existing global resource to be configured as a regional resource
      --from stringArray   A peer to match, one of:
                             service:NAME             a service in the local project
                             service:NAME@PROJECT_ID  a service in another project
                             project:PROJECT_ID       all services in another project
                             cidr:CIDR[,EXCEPT...]    an IP block, optionally excluding one or more sub-blocks
                           Can be passed multiple times; a rule with no peers allows traffic from/to all sources/destinations.
  -h, --help               help for ingress-rule
      --owner string       the owner of the project to use, needed if you have two projects with the same name from different owners
      --port stringArray   A port to allow traffic on, one of:
                             N             a numeric port, eg 8080
                             N/PROTO       a numeric port with an explicit protocol, eg 8080/UDP (protocol is one of TCP, UDP, SCTP; defaults to TCP)
                             N-M           a numeric port range, eg 8080-8090
                             N-M/PROTO     a numeric port range with an explicit protocol
                             akka-service  traffic to a service over the internal Akka service protocol
                           Can be passed multiple times; a rule with no ports allows traffic on all ports.
      --project string     project to use if not using the default configured project
      --region string      region to use if project has more than one region
----
