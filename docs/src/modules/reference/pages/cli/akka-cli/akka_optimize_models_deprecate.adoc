= akka optimize models deprecate

Mark a model version for replacement

== Synopsis

Deprecate a model version in the registry, recording you, the time and the reason.

The reference names a version number.
The command reads the version first, and refuses an alias, latest, a digest and a version the registry does not hold before it asks anything.
Routes to a deprecated version keep serving, and the gateway router accepts a routing write that reaches it with a warning.
The command lists each destination record, rule and manifest that still reaches the version: beside the question, or on stderr after the move when no question is put.

[source,shell]
----
akka optimize models deprecate NS/NAME:vN --reason TEXT [flags]
----

== Examples

[source,shell]
----
  akka optimize models deprecate triage/classifier:v2 --reason "replaced by v3"
----

== Options

[source,text]
----
  -h, --help            help for deprecate
      --reason string   Why, recorded on the version
----
