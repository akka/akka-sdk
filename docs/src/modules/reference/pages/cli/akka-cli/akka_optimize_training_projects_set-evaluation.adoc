= akka optimize training projects set-evaluation

Set evaluation dataset and grader for a training project

== Synopsis

Configure the evaluation dataset and grader used to compare candidate models for a training project.

Score comparisons require matching dataset and grader pairs.
Updating either value resets the default baseline comparison table.
Previous evaluation scores remain accessible by supplying --dataset and --grader to the "scores" command.

[source,shell]
----
akka optimize training projects set-evaluation PROJECT --dataset NS/NAME [flags]
----

== Examples

[source,shell]
----
  # Set the evaluation dataset
  akka optimize training projects set-evaluation commit-router --dataset eval-set

  # Set both evaluation dataset and grader
  akka optimize training projects set-evaluation commit-router \
    --dataset 4b1c2f9b2ae4 --grader model:triage/judge:v1
----

== Options

[source,text]
----
      --dataset string               Evaluation dataset, by registry reference
      --grader string                Grader specification: json-label-match, model:NS/NAME[:VERSION], or http:URL
      --grader-instructions string   Instructions a model: grader is asked under, in place of the ones it would otherwise get
  -h, --help                         help for set-evaluation
----
