= akka organizations roles

Manage organization custom roles.

== Synopsis

The `akka organizations roles` commands manage the custom roles of an organization.
A custom role is a policy made up of rules, each of which grants permissions on resources of the organization.
Once created, a custom role can be granted to principals by creating a role binding to it, using `akka organizations role-bindings add --custom-role`.

Custom roles are described by a YAML descriptor, which is the same as the protobuf representation of a custom role, except that it has an id field, containing just the id of the role, instead of a name field.
For example:

id: project-deployer   description: Can view and deploy to all projects   rules:     - resources: ["projects/_"]       permissions: ["project.get", "project.services._"]     - roles: ["roles/organization/viewer"]

Use `akka organizations roles export` to export an existing role as a starting point.

Changes to custom roles are eventually consistent, they may take some time to be applied.

For more details, see https://doc.akka.io/operations/security/custom-roles.html .
