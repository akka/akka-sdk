= akka optimize spend recent

The most recent model calls, newest first

== Synopsis

Each row is one model call: when it was served, the system id it named, its tags, the model, the provider the price catalog names for it, whether it was answered, what it consumed and what it cost.

A model call is listed only once its capture has shipped and been read, so the newest ones may not be here yet.
The service states how far its records reach.

[source,shell]
----
akka optimize spend recent --since INSTANT [flags]
----

== Options

[source,text]
----
  -h, --help            help for recent
      --limit int       how many model calls to list; the service states the default
      --since string    the earliest instant a model call was served at, an ISO-8601 instant in UTC, inclusive
      --system string   list only the model calls of this system id, the one a request named in
                        x-akka-system-id
      --tag string      list only the model calls carrying this tag, as KEY:VALUE, where KEY is the name
                        of one of your tagging rulesets
----
