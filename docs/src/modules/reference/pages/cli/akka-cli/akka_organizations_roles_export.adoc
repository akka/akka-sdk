= akka organizations roles export

Export a custom role of the organization as a YAML descriptor.

== Synopsis

Export a custom role of the organization as a YAML descriptor.
The descriptor can be edited and then used with `akka organizations roles update`, or with `akka organizations roles create` after changing its id to create a copy of the role.

[source,shell]
----
akka organizations roles export ROLE_ID [flags]
----

== Examples

[source,shell]
----
akka organizations roles export my-role -f my-role.yaml
----

== Options

[source,text]
----
  -f, --file string           The YAML descriptor file. If not supplied, will write to stdout.
  -h, --help                  help for export
      --organization string   name or ID for organization
----
