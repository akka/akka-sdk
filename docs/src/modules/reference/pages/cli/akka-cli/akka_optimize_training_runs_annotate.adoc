= akka optimize training runs annotate

Update annotations and configuration name for a training run

== Synopsis

Set a description or configuration display name for a training run.

Annotations do not modify run identifiers or references.
You can annotate a run at any point during or after execution.

The value of --config-name appears as the column header in "training workloads scores".
If runs of the same configuration have different names, the most recently set name is used.

----
akka optimize training runs annotate RUN [flags]
----

== Examples

----
  # Add a description to a run
  akka-optimize training runs annotate 7d496e82c3a15f04 --description "Baseline sweep"

  # Set a configuration name for score comparison tables
  akka-optimize training runs annotate 7d496e82c3a15f04 --config-name rank16-lr2e-4
----

== Options

----
      --config-name string   Column header for this configuration in comparison tables. Pass an empty string to clear
      --description string   Description for the resource. Pass an empty string to clear
  -h, --help                 help for annotate
----
