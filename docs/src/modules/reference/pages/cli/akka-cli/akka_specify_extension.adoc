= akka specify extension

[Incubating] Verify an auditor or a probe against the extension contract.

== Synopsis

[Incubating] An auditor or a probe is a command that reads a JSON request on standard input and writes a JSON answer on standard output.
'verify' puts a battery of requests to one and reports whether it speaks that contract, including the requests it cannot answer.
