= akka optimize registry bundles annotate

Set or clear the description of a bundle version

== Synopsis

An omitted description leaves the note unchanged.
An empty string clears it.

A reference is one string: NS/NAME for the named artifact, NS/NAME:v2 for a version, NS/NAME:serving for the version an alias points at, and NS/NAME@sha256:...
for a version by digest.
NS/NAME where a version is wanted is the newest version.

----
akka optimize registry bundles annotate NS/NAME[:REF] --description TEXT [flags]
----

== Options

----
      --description string   Description for the resource. Pass an empty string to clear
  -h, --help                 help for annotate
----
