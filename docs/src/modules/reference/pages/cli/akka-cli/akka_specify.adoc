= akka specify

[Incubating] Initialize and manage AI-assisted Akka development projects.

== Synopsis

[Incubating] The 'akka specify' commands set up Akka projects for AI-assisted development.
Use 'akka specify init' to create a new project with all the resources needed for AI coding agents, including slash commands, templates, and MCP configuration.
