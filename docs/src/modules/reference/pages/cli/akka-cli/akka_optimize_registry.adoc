= akka optimize registry

The artifact registry: named models, datasets and bundles

== Synopsis

A namespace groups the artifacts of one piece of work across all three kinds.
A named artifact owns an ordered list of immutable versions and a set of movable aliases.

Registering content whose digest a version of that name already has returns that version and appends nothing.

A reference is one string: NS/NAME for the named artifact, NS/NAME:v2 for a version, NS/NAME:serving for the version an alias points at, and NS/NAME@sha256:...
for a version by digest.
NS/NAME where a version is wanted is the newest version.
