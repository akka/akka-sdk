= akka optimize training curations list

List curation runs

== Synopsis

List curation runs, newest first, with what each kept of what it extracted.

--phase active lists the curations still running, and a phase name lists the curations in it.
--search lists the curations whose ID starts with the prefix, comparing letters and digits only.
--session lists the curations made from one session, by its whole hash, and combines with neither --phase nor --search.
--offset and --limit page through a long list.
Where more curations remain, the command names the --offset of the next page.

[source,shell]
----
akka optimize training curations list [--phase PHASE] [--search PREFIX] [--session HASH] [--offset N] [--limit N] [flags]
----

== Examples

[source,shell]
----
  # List the newest curations
  akka optimize training curations list

  # Extract curation IDs using jq
  akka optimize training curations list --jq '.curations[].curationId'
----

== Options

[source,text]
----
  -h, --help             help for list
      --limit int        Number of entries on the page to print, at most 100. With --offset alone, the page holds 50
      --offset int       Index of the first entry to return. With --offset or --limit, the list prints that one page
      --phase string     Filter by phase. Pass 'active' to list unfinished entries ('open' is another word for it) and 'finished' to list the rest
      --search string    Only the curations whose ID starts with this prefix, in any case
      --session string   Only the curations made from this session, by its whole hash
----
