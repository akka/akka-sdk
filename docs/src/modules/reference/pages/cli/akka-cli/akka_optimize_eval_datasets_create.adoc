= akka optimize eval datasets create

Upload a dataset file and version it

== Synopsis

Uploads a dataset and imports it.

FILE is a zip of dataset.json and items.jsonl, which is the form that can create a dataset: the manifest is what names it.
A bare items.jsonl, gzipped or not, carries cases alone and adds a version to a dataset that already exists -- name it with --into, and the manifest that dataset recorded is reused.

The service reads the leading bytes rather than the file name, so a .zip that is really gzip, or the other way round, still imports.

----
akka optimize eval datasets create -f FILE [flags]
----

== Options

----
  -f, --file string   the dataset to upload: a zip, an items.jsonl, or a gzipped one; - reads stdin
  -h, --help          help for create
      --into string   add a version to this existing dataset, reusing the manifest it recorded
----
