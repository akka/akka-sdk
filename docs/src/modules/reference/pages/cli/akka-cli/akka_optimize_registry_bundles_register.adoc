= akka optimize registry bundles register

Upload and register an independently versioned bundle

== Synopsis

Register an exact ZIP file or deterministically package a directory and register it.

Directory packaging includes every regular file, hidden file, cache file and empty directory.
Paths are sorted, timestamps are fixed and modes are normalized.
Symbolic links and special files are refused.
Supplying a ZIP preserves its bytes exactly.

The client asks whether the digest is already present before uploading bytes.
--alias points an alias at the returned version.
The consumer owns modules, functions and scoring policy.

----
akka optimize registry bundles register NS/NAME -f ZIP_OR_DIRECTORY [flags]
----

== Examples

----
  # Package a directory and register it
  akka-optimize registry bundles register spider/scoring -f ./scoring --alias candidate

  # Preserve and register an existing ZIP
  akka-optimize registry bundles register spider/scoring -f scoring.zip
----

== Options

----
      --alias string   Point this alias at the registered version
  -f, --file string    Path to an exact ZIP or a directory to package
  -h, --help           help for register
----
