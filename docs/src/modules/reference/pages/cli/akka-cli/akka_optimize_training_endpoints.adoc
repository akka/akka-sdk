= akka optimize training endpoints

Serve a base model or a candidate to try it by hand

== Synopsis

An endpoint makes a model answerable at an OpenAI-compatible address.

An endpoint is the deployment rather than the model.
A serving process holds a bounded number of adapters over one resident copy of its base model, so a candidate whose base model is already served attaches to that endpoint: it answers in seconds and claims no further devices.
What tells the models at one address apart is the model name a request asks for.

This is the one thing in the training service that holds GPUs while nothing is happening, which is why an endpoint is a deliberate act and why deleting one is worth doing when you are finished with it.
Training and evaluation need no endpoint;
they load what they need and release it.

== Examples

----
  # Serve a selected base model
  akka-optimize training endpoints create --model Qwen/Qwen3-8B --workload triage

  # Serve a candidate, which attaches to its base model's endpoint
  akka-optimize training endpoints create --model triage-candidate

  # Wait for one that is already coming up
  akka-optimize training endpoints wait 970076e8

  # Send it one input
  akka-optimize training endpoints send 970076e8 --input "Is this ticket a billing problem?"

  # Stop answering for one model
  akka-optimize training endpoints detach 970076e8 triage-candidate
----
