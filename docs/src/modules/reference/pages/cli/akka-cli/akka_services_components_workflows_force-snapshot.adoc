= akka services components workflows force-snapshot

Create a state snapshot of a single workflow instance now.

== Synopsis

The `akka service components workflows force-snapshot` command creates a state snapshot of a single workflow instance now, without waiting for the configured number of events.
Use it after a state schema change, to store the current state in the new format.
The command is rejected when snapshots are disabled for the component.
It does nothing, and reports success, for an instance that has no events yet or that has been deleted.

A snapshot change applies only in the region it is sent to.
In a project with more than one region, pass --all-regions to run in every region, or --region REGION to run in one.
A single-region project needs neither.

----
akka services components workflows force-snapshot SERVICE_NAME COMPONENT_ID WORKFLOW_ID [flags]
----

== Options

----
      --all-regions      run the command in every region of the project
  -h, --help             help for force-snapshot
      --owner string     the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string   project to use if not using the default configured project
      --region string    region to use if project has more than one region
----
