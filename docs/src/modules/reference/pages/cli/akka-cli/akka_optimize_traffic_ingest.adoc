= akka optimize traffic ingest

Run recorded exchanges as traffic served at their recorded times

== Synopsis

FILE holds JSON Lines, one recorded exchange each, in the format described under "Ingesting recorded traffic" in docs/gateway-router.md.

The file is sent in parts of --lines-per-request lines, one part at a time and in file order, so the turns of a conversation run in the order the file gives them.
The router checks every line of a part before any of them runs.
A part it refuses stops the command: the parts before it have run, and the parts after it are not sent.

A line the router answers with an error did not finish.
The lines after it still run, and the command exits non-zero once the file has been sent.

The router answers a part once every line in it has run.
A part that is not answered in time, because the router's request timeout or --timeout passed first, may still be running.
Do not ingest that part again until its lines have finished.

----
akka optimize traffic ingest -f FILE [flags]
----

== Examples

----
  akka-optimize traffic ingest -f traffic.jsonl
  akka-optimize traffic ingest -f traffic.jsonl --lines-per-request 10 -o json
----

== Options

----
  -f, --file string             recorded exchanges, one JSON line each; - reads stdin
  -h, --help                    help for ingest
      --lines-per-request int   the most lines one request carries, at most the router's gateway.ingest.max-lines-per-request; a part also stays within 8 MiB (default 30)
----
