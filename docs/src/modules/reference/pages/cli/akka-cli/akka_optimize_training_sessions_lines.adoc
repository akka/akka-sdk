= akka optimize training sessions lines

Print the recorded conversations of one session

== Synopsis

Print the recorded conversations of one session, one JSON line each, as the upload held them, in upload order.
Blank lines of the upload are left out.

HASH is the session's whole hash or the start of it, as "training sessions list" prints it.
A start that several sessions share is refused, naming them.

--offset is the first line, from 0.
--limit is how many lines to read, up to 1000.
The service also stops a read at 4 MiB, at a whole line, so a read can hold fewer lines than --limit.
Where more lines remain, the command names the --offset of the next read.

A session recorded without pages is refused.
Upload the same corpus again to store its pages.

[source,shell]
----
akka optimize training sessions lines HASH [--offset N] [--limit N] [flags]
----

== Examples

[source,shell]
----
  # Print the first 20 conversations of a session
  akka optimize training sessions lines 3e1f9a --limit 20

  # Print the next 20
  akka optimize training sessions lines 3e1f9a --offset 20 --limit 20

  # Every line as one JSON document
  akka optimize training sessions lines 3e1f9a -o json
----

== Options

[source,text]
----
  -h, --help         help for lines
      --limit int    Read at most this many lines, up to 1000; 0 takes the service's most
      --offset int   The first line to read, from 0
----
