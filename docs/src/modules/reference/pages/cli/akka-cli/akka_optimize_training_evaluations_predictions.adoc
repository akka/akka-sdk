= akka optimize training evaluations predictions

Display predicted and expected answers for an evaluation

== Synopsis

Display per-example evaluation results: the example's position in the split, the prompt it asked, the expected output, the model's answer, the score, and the grader's explanation.

Examples where the grader cannot determine a verdict are marked as unscored rather than scored as zero.

Results are available while the evaluation is in progress.

----
akka optimize training evaluations predictions EVALUATION [flags]
----

== Examples

----
  # Display the first 5 predictions
  akka-optimize training evaluations predictions 9c2e4b7a1d63f085 --limit 5

  # Filter incorrect predictions using jq
  akka-optimize training evaluations predictions 9c2e4b7a1d63f085 \
    --jq '.[] | select(.score == 0)'

  # Filter unscored predictions where the grader returned no verdict
  akka-optimize training evaluations predictions 9c2e4b7a1d63f085 \
    --jq '.[] | select(.score == null)'
----

== Options

----
  -h, --help        help for predictions
      --limit int   Limit output to the specified number of examples
----
