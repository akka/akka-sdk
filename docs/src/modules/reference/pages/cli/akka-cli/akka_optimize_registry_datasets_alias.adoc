= akka optimize registry datasets alias

The movable pointers into a named dataset

== Synopsis

An alias points at one version of its named dataset, moves to another, and keeps every version it has pointed at.
Moving an alias changes no version.

'latest' is the registry's own alias.
It always points at the newest version, and no command sets or removes it.
