= akka optimize eval

Datasets, experiments and the evaluators that score them

== Synopsis

An experiment is one execution of one dataset version against one target with one set of evaluators.

An evaluator never turns a failure into a low score: it reports inconclusive when it has nothing to read, and neither that nor its own breakage enters a pass rate.
