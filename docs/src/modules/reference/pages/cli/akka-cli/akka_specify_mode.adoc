= akka specify mode

Show or set the local project mode.

== Synopsis

[Incubating] Show or set the local project mode.
When an org policy locks the mode, only the org-allowed mode(s) may be set -- a locked enforced mode cannot be dropped to à-la-carte to bypass the ship gate.

----
akka specify mode [enforced|a-la-carte] [flags]
----

== Options

----
      --dir string      project directory (default: current)
  -h, --help            help for mode
      --policy string   path to an org governance policy-as-code file (policy.yaml)
----
