= akka optimize training distillations

Manage distillations

== Synopsis

A distillation uses a teacher model to answer every decision in a source chat dataset.
It keeps accepted answers for a target dataset.

A decision is one assistant message in a source row.
Specify it as ROW:MESSAGE, with row and message indexes starting at zero.
The teacher first answers the smoke decisions on one GPU.
Once the smoke passes, it answers decisions across the whole source on its replicas, with one GPU each.
It saves answers in chunks.

== Examples

[source,shell]
----
  # Start a distillation
  akka optimize training distillations create --project support-triage \
    --teacher google/gemma-4-31b-it:v1 --from triage/conversations:v2 --to triage-distilled

  # Follow it until it stops
  akka optimize training distillations wait 4b1f0c2e9a7d

  # List the rejected answers
  akka optimize training distillations rejections 4b1f0c2e9a7d --limit 20
----
