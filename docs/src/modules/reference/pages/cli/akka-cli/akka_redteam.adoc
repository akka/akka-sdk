= akka redteam

Adversarial datasets, red-team campaigns, techniques, hazards and corpora.

== Synopsis

Runs the red-team pack against your service. Shares vocabulary and runtime with `akka eval`; adds attack styles, a hazard taxonomy, and adversarial corpora. Never rolls findings up into a single aggregate score.

----
akka redteam [command]
----

== Options

----
  -h, --help   help for redteam
----
