= akka organizations stores

List the store clusters your organization may pin a project to

== Synopsis

The `akka organizations stores` commands show the Postgres store clusters your organization may pin a project to with `akka project new --store`.
A store is pinned per region, so a store usable by a multi-region project must be declared under the same name in every region that project will run in.
