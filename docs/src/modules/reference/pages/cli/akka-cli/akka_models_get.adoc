= akka models get

Describe one model;
--wait blocks until it is Ready.

== Synopsis

Shows the model and, when it is not ready, the Ready condition's own reason: an engine that is still pulling weights, a device that will not bind, or an entitlement that was revoked each name themselves.

--wait polls until Ready is True or --wait-timeout passes.
The first deployment of a model pulls the engine image and the checkpoint, so minutes are normal.

----
akka models get NAME [flags]
----

== Examples

----
akka models get docs
akka models get docs --wait --wait-timeout 15m
----

== Options

----
  -h, --help                    help for get
      --owner string            the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string          project to use if not using the default configured project
      --region string           region to use if project has more than one region
      --wait                    Wait until the model is Ready.
      --wait-timeout duration   How long --wait waits. (default 10m0s)
----
