= akka optimize training base-models candidates

List an author's repositories and what this deployment would make of each

== Synopsis

List the repositories an author publishes, with the verdict on each.

The verdict is the one admission reaches: whether the pinned engines support the architecture, whether a device profile holds a model that size, and whether it can be served with LoRA.
Nothing is allowed or selected by asking.

--match is a glob over the repository name, applied to what the hub returned rather than passed to it: the hub's search is ranked rather than exact, and asking it for gemma-3 answers with gemma-4 models too.

--catalog prints the entries to paste into a region's catalog.conf, pinned to the commits this resolved.
Envelopes are not written: an envelope is a measurement, and each entry says so until somebody has made it.

----
akka optimize training base-models candidates --author AUTHOR [--match GLOB] [flags]
----

== Examples

----
  # What the Gemma 4 family offers, and which members this deployment could train
  akka-optimize training base-models candidates --author google --match 'gemma-4-*'

  # The catalog entries for the ones it could
  akka-optimize training base-models candidates --author google --match 'gemma-4-E4B*' --catalog
----

== Options

----
      --author string   The hub account that publishes the repositories
      --catalog         Print catalog.conf entries for the admissible candidates instead of a table
  -h, --help            help for candidates
      --match string    Glob over the repository name, such as 'gemma-4-*'. Every repository by default
----
