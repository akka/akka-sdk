= akka services components consumers reset-offset

Reset a Consumer's offset so it reprocesses its source from the beginning.

== Synopsis

The `akka service components consumers reset-offset` command resets the offset of a Consumer component, so that it reprocesses its source from the beginning.
A Consumer that starts from snapshots restarts from its snapshots instead.
Events from before the start-from timestamp of the Consumer or the service are still skipped.

This cannot be undone.
Events are redelivered, so any side effects the Consumer already produced from them, such as topic publishes, happen again.
A paused Consumer is reset but stays paused.

The command returns once the offset is reset, not when the replay has finished.
Use `akka service components check-progress` to follow it, with a watermark of the producing service for a Consumer of a service stream.
If the command is interrupted, the reset may still complete in the runtime.

A reset applies only in the region it is sent to.
In a project with more than one region, pass --all-regions to run in every region, or --region REGION to run in one.
A single-region project needs neither.

Not supported for Views (use `akka service views drop` for an inactive View), for Consumers sourced from a broker topic, or for Consumers that produce a service stream.

[source,shell]
----
akka services components consumers reset-offset SERVICE_NAME COMPONENT_ID [flags]
----

== Examples

[source,shell]
----

> akka service components consumers reset-offset customer-registry my-consumer
> akka service components consumers reset-offset customer-registry my-consumer --all-regions
----

== Options

[source,text]
----
      --all-regions      run the command in every region of the project
  -f, --force            Skip the confirmation prompt.
  -h, --help             help for reset-offset
      --owner string     the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string   project to use if not using the default configured project
      --region string    region to use if project has more than one region
----
