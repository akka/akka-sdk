= akka optimize training curations apply

Start a curation run

== Synopsis

Judging calls a model once per extracted candidate, so a curation over a large corpus runs for as long as that many model calls take.
--wait follows it, reporting how many candidates have been judged of how many there are.

----
akka optimize training curations apply -f FILE [flags]
----

== Examples

----
  akka-optimize training curations apply -f curation.json
  akka-optimize training curations apply -f curation.json --wait
----

== Options

----
      --exit-status   exit non-zero unless it completed
  -f, --file string   curation request; - reads stdin
  -h, --help          help for apply
      --wait          follow it until it finishes
----
