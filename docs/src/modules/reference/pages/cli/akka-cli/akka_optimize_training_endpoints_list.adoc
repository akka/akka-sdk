= akka optimize training endpoints list

List endpoints

== Synopsis

List endpoints, newest first.

MODELS is how many models one endpoint serves.
An endpoint that is AWAITING_CAPACITY is queued behind other work for its devices.
Use --project to list the endpoints one training project brought up, named by its name or ID.

A row of an archived training project is left out unless --archived is given or --project names that project.
Such a row is marked "(archived)".

[source,shell]
----
akka optimize training endpoints list [flags]
----

== Examples

[source,shell]
----
  # List endpoints
  akka optimize training endpoints list

  # Name the ones answering
  akka optimize training endpoints list --jq '.endpoints[] | select(.phase=="READY") | .endpointId'
----

== Options

[source,text]
----
      --archived         Include the endpoints of archived training projects
  -h, --help             help for list
      --project string   List only the endpoints this training project brought up, by name or ID
----
