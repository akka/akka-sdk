= akka optimize training distillations get

Display details for a distillation

== Synopsis

Display a distillation's configuration, progress, rejections, smoke result and GPU time.
Also display the dataset version registered from its accepted answers.

[source,shell]
----
akka optimize training distillations get DISTILLATION [flags]
----

== Examples

[source,shell]
----
  # Display distillation details
  akka optimize training distillations get 4b1f0c2e9a7d

  # Follow progress until the distillation stops
  akka optimize training distillations get 4b1f0c2e9a7d --follow

  # Extract the accepted count using jq
  akka optimize training distillations get 4b1f0c2e9a7d --jq .progress.decisions.accepted
----

== Options

[source,text]
----
      --exit-status   Exit with a non-zero status if the distillation fails or is cancelled. Requires --follow
      --follow        Stream status updates until the distillation stops
  -h, --help          help for get
----
