= akka optimize training workloads

Manage training workloads

== Synopsis

A workload defines a training target, specifying the dataset and grader used to evaluate candidate models, along with reference pointers to model entries.

Runs and models reference workloads by immutable ID rather than name, so renaming a workload preserves all associations.
Workload commands accept either workload name or ID.

Workloads support three standard reference pointers: "base" points to the baseline model, while "candidate" and "champion" track models under evaluation or in active use.

== Examples

----
  # Create a workload with an evaluation dataset
  akka-optimize training workloads create commit-router --dataset eval-set

  # Set the base model reference pointer
  akka-optimize training workloads refs set commit-router base 4f3a91c07b2e5d68

  # Compare candidate model scores against the baseline
  akka-optimize training workloads scores commit-router
----
