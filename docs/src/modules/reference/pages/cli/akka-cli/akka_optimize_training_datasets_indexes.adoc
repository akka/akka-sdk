= akka optimize training datasets indexes

List rows indexes, newest first

== Synopsis

List the rows indexes, newest first, each as its last attempt: every index, or those started for one namespace, or for one named dataset in it with --dataset.

An index serves every name of the same rows, and is listed under the version it was started for.
ROWS is the rows an index holds once it is done, and how many it has indexed so far while it runs.

-o json prints the list as Optimize sends it.

[source,shell]
----
akka optimize training datasets indexes [NAMESPACE] [--dataset NAME] [flags]
----

== Examples

[source,shell]
----
  # List the indexes of a namespace
  akka optimize training datasets indexes triage

  # List the indexes of one named dataset
  akka optimize training datasets indexes triage --dataset train
----

== Options

[source,text]
----
      --dataset string   Only the indexes of this named dataset of the namespace
  -h, --help             help for indexes
----
