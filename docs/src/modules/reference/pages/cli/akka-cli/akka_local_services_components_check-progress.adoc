= akka local services components check-progress

Check if a view or consumer has caught up with a watermark.

== Synopsis

The `akka local service components check-progress` command compares the progress of a view or consumer with a watermark.
The command fails when the component has not caught up.

For a Kalix service COMPONENT_ID is the view id, or the gRPC service name of a view or of an action with subscriptions.

A watermark of the service's own entities is taken as part of the check.
That covers views and consumers of entities in the same service.

For a service to service consumer take the watermark on the producing service with `akka local service components get-watermark` and pass it with `--watermark`.
Pass one watermark file per producing service when a view has sources from several services.
Entity types in the watermark that the component does not consume are ignored.

Timestamps are only comparable within one region.
A watermark from another region is not used.
Run the check in every region of interest with a watermark from that region.

Sources that cannot be verified are listed and do not count towards the result.
These are topic sources and sources without a matching watermark.
The command fails when no source could be verified.

Events committed late, within the backtracking window of the event queries before the watermark, can still arrive after the check.
When that matters, run the check again once the backtracking window plus the behind-current-time of the event queries has passed since the watermark was taken.

[source,shell]
----
akka local services components check-progress SERVICE_NAME COMPONENT_ID [flags]
----

== Examples

[source,shell]
----
akka local service components check-progress my-service my-view
akka local service components check-progress my-service my-consumer --watermark upstream-watermark.json
----

== Options

[source,text]
----
  -h, --help                    help for check-progress
      --owner string            the owner of the project to use, needed if you have two projects with the same name from different owners
      --project string          project to use if not using the default configured project
      --region string           region to use if project has more than one region
      --watermark stringArray   A watermark JSON file from a producing service, or - for standard input. Can be given several times.
----
