= akka specify attest

Record an attestation that a delegated check ran externally, or a harness was activated.

== Synopsis

[Incubating] A delegated check runs in an external system (a central SAST service, a SIEM) or reflects a judgment the CLI cannot make.
Recording an attestation -- a receipt the engine trusts in place of running the check -- resolves the condition or covers the harness capability.
Pass a condition id or a harness capability name (for example sast).

----
akka specify attest <key> [flags]
----

== Options

----
      --dir string   project directory (default: current)
  -h, --help         help for attest
      --ref string   receipt reference (run URL, signature, or rubric hash)
