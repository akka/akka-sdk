= akka optimize redteam

Adversarial datasets, red-team campaigns, techniques, hazards and corpora

== Synopsis

Runs the red-team pack against your service.
Shares vocabulary and runtime with the eval subtree;
adds attack styles, a hazard taxonomy, and adversarial corpora.

Never rolls findings up into a single aggregate score.
Reports always break out by hazard and by technique.
