= akka models endpoints keys

Manage an endpoint's API keys.

== Synopsis

Keys live as entries of the secret the endpoint's apiKeySecret names, one entry per client.
Rotation is add-then-remove: add a key for the new name, move the client over, remove the old one.
There is no cutover moment.
