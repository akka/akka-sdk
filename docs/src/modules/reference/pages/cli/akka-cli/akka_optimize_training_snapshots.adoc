= akka optimize training snapshots

Inspect snapshots and candidate registration

== Synopsis

A snapshot is an immutable save of a training run that the catalog has verified.

Weights and full training state are committed separately.
Weights can start a branch or be registered as a candidate model.
Full training state can resume a run and, on a supported backend, start a branch with optimizer state.
A snapshot that holds only training state is not a servable model.

A snapshot is swept under the run's keep counts unless a holder retains it.
Use "training snapshots pin" to retain one for as long as you need it.

Snapshots are listed per run with "training runs snapshots".

== Examples

----
  # List the snapshots a run committed
  akka-optimize training runs snapshots 7d496e82c3a15f04

  # Register one of them as a model and score it
  akka-optimize training snapshots register 3f2a9c71bd04e5a2...

  # Retain a snapshot to branch from later
  akka-optimize training snapshots pin 3f2a9c71bd04
----
