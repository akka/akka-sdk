= akka eval campaigns compare

A campaign against a baseline, item by item.

== Synopsis

Reads by default; `--assert` turns it into a claim that fails on regression.

----
akka eval campaigns compare ID --baseline ID [flags]
----

== Options

----
      --assert            fail on regression
      --baseline string   the campaign to compare against
  -h, --help              help for compare
----
