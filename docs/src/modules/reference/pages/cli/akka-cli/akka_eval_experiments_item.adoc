= akka eval experiments item

One item's run, and what each scorer said about it.

== Synopsis

Prints the transcript and per-scorer verdicts for one scenario.

----
akka eval experiments item CAMPAIGN ITEM [flags]
----

== Options

----
  -h, --help   help for item
----
