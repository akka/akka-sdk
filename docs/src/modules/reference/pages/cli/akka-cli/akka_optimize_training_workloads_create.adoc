= akka optimize training workloads create

Create a new training workload

== Synopsis

Create a training workload and display its assigned ID.

The --dataset and --grader flags specify the evaluation dataset and grader used to score candidate models.
--grader applies with --dataset, and defaults to json-label-match.
You can also configure or update these settings later using "training workloads set-evaluation".

----
akka optimize training workloads create NAME [flags]
----

== Examples

----
  # Create a workload
  akka-optimize training workloads create commit-router

  # Create a workload with evaluation settings
  akka-optimize training workloads create commit-router \
    --dataset eval-set --grader json-label-match
----

== Options

----
      --dataset string   Evaluation dataset name or hash
      --grader string    Grader specification: json-label-match, model:MODEL, or http:URL
  -h, --help             help for create
----
