= akka optimize training runs branches

List child runs created from a parent run

== Synopsis

List child runs created from a parent run's source snapshots, newest first.

SOURCE STEP is the saved step represented by the source snapshot.
Each child run counts its own updates from zero.
Use "training runs get" to see a child's observed step and saved step.

CONFIG identifies the child configuration.
The response document also includes the parent configuration hash for comparison.

The list is eventually consistent, so a newly created child may not appear immediately.
Use --submission to read the current preparation state directly.

----
akka optimize training runs branches PARENT [flags]
----

== Examples

----
  # List the runs started from a run's snapshots
  akka-optimize training runs branches 7d496e82c3a15f04

  # Read how far one submission got
  akka-optimize training runs branches 7d496e82c3a15f04 --submission 9f14c0a7

  # Compare the two children of one experiment using jq
  akka-optimize training runs branches 7d496e82c3a15f04 \
    --jq '.branches[] | [.childRunId, .configHash, .budgetSteps]'
----

== Options

----
  -h, --help                help for branches
      --limit int           Maximum number of entries to return. The service defaults to 50 and allows at most 100
      --offset int          Index of the first entry to return
      --submission string   Read one submission's preparation state instead of listing child runs
----
