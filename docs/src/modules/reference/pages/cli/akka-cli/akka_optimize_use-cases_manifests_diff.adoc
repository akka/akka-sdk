= akka optimize use-cases manifests diff

A manifest against the working set as it stands now

== Synopsis

The working set stays live after a freeze, which is what this compares against.

A rising below-threshold share has two causes -- traffic the manifest does not describe, and traffic the working set cannot admit because the cap is full -- so the cap is reported beside it.

----
akka optimize use-cases manifests diff TAG [flags]
----
