= akka optimize training evaluations list

List model evaluations

== Synopsis

List evaluations and their scores, optionally filtered by workload, model or phase.
The filters combine, so a workload and a phase together list that workload's unfinished evaluations.

--workload takes a name or an id, which is what scored against a workload's quota.
It is the same flag "evaluations start" takes.

----
akka optimize training evaluations list [flags]
----

== Examples

----
  # List all evaluations
  akka-optimize training evaluations list

  # List evaluations for a model
  akka-optimize training evaluations list --model 4f3a91c07b2e5d68

  # List what a workload has scored
  akka-optimize training evaluations list --workload support-triage

  # List active and incomplete evaluations
  akka-optimize training evaluations list --phase open

  # Filter low-scoring evaluations using jq
  akka-optimize training evaluations list \
    --jq '.evaluations[] | select(.meanScore < 0.5) | .evaluationId'
----

== Options

----
  -h, --help              help for list
      --model string      Filter evaluations by model ID
      --phase string      Filter by phase. Pass 'open' to list unfinished entries
      --workload string   Filter evaluations by the workload they scored against, by name or ID
----
