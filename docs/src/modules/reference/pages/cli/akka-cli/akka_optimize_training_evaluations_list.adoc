= akka optimize training evaluations list

List model evaluations

== Synopsis

List evaluations and their scores, optionally filtered by training project, model or phase.
The filters combine, so a training project and a phase together list that training project's unfinished evaluations.

--project takes a name or an id, which is what scored against a training project's quota.
It is the same flag "evaluations start" takes.

[source,shell]
----
akka optimize training evaluations list [flags]
----

== Examples

[source,shell]
----
  # List all evaluations
  akka optimize training evaluations list

  # List evaluations for a model
  akka optimize training evaluations list --model labeler/qwen3-0.6b:v3

  # List what a training project has scored
  akka optimize training evaluations list --project support-triage

  # List active and incomplete evaluations
  akka optimize training evaluations list --phase open

  # Filter low-scoring evaluations using jq
  akka optimize training evaluations list \
    --jq '.evaluations[] | select(.meanScore < 0.5) | .evaluationId'
----

== Options

[source,text]
----
  -h, --help             help for list
      --model string     Filter evaluations by model, as a registry reference NS/NAME[:VERSION]. With --project, NAME[:VERSION] names a model in that project's namespace
      --phase string     Filter by phase. Pass 'open' to list unfinished entries
      --project string   Filter evaluations by the training project they scored against, by name or ID
----
