= akka optimize training capacity device-hours

Report the device-hours claims held in a period

== Synopsis

Report the device-hours that GPU claims held between two instants, one row per pool or per endpoint.

A claim counts its devices from when the scheduler granted them until it released them, and a claim still held counts until now.
Every time is one the scheduler recorded, so a figure does not change with how often it is read.

KEY is the pool's key, or with --by endpoint the endpoint's id.
POOL is, for an endpoint, the pool its devices were counted in last.
DEVICE HOURS is devices multiplied by the hours they were held in the period.
HELD says whether the pool or the endpoint holds devices now.

--from and --to are ISO-8601 instants, such as 2026-10-01T00:00:00Z.
--to defaults to now and --from to a day before --to.
They are at most 366 days apart.
--by is pool, the default, which counts every claim, or endpoint, which counts the claims of endpoints alone.

[source,shell]
----
akka optimize training capacity device-hours [flags]
----

== Examples

[source,shell]
----
  # The last day, by pool
  akka optimize training capacity device-hours

  # One month, by endpoint
  akka optimize training capacity device-hours --from 2026-10-01T00:00:00Z --to 2026-11-01T00:00:00Z --by endpoint

  # The endpoints holding devices now
  akka optimize training capacity device-hours --by endpoint --jq '.rows[] | select(.held) | .key'
----

== Options

[source,text]
----
      --by string     Count by pool or by endpoint (default pool)
      --from string   Count from this ISO-8601 instant (default a day before --to)
  -h, --help          help for device-hours
      --to string     Count until this ISO-8601 instant (default now)
----
