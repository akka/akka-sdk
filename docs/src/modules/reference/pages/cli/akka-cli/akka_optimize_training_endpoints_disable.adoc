= akka optimize training endpoints disable

Refuse requests for one model while it stays attached

== Synopsis

Refuse requests for one model at an endpoint.
ENDPOINT and MODEL are named as "detach" names them.

The model stays attached and the endpoint keeps its devices, so "enable" makes it answer again at once.
A request for a disabled model through the trainer is answered with 409.
A caller inside the deployment's network that sends to the endpoint's address directly is not refused.
The judge a run still holds is not disabled.

[source,shell]
----
akka optimize training endpoints disable ENDPOINT MODEL [flags]
----

== Examples

[source,shell]
----
  # Stop answering for one candidate without detaching it
  akka optimize training endpoints disable 970076e8 triage/candidate:v3
----
