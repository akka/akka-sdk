= akka optimize use-cases

Discovered use-cases, and the manifests frozen from them

== Synopsis

A use-case here is the gateway router's: a cluster of traffic that means roughly the same thing, discovered from what the deployment actually served.
A freeze fixes that clustering as something routable.

The assessment use-cases are a second surface under the same noun -- candidacy, or how worth specializing a workload is, scored by the assessment service.
They are hidden until the two surfaces are reconciled, so nothing here reads candidacy.
