= akka optimize redteam init

Add the red-team source root to a project

== Synopsis

Writes the red-team tree -- scorers by family, adversarial datasets, rubrics, baselines, custom-technique files, corpora -- into the existing project's src/test/java and adds the redkit dependency to the project pom at test scope.
Campaigns are ordinary JUnit tests gated on -Dredteam=true, so `mvn verify` compiles them without running them;
`mvn verify -Dredteam=true` runs them.

Additive: a file already present is left alone.
--force replaces them, after backing up what it replaces.

After init, pull adversarial corpora with `akka-optimize redteam corpora pull`.

----
akka optimize redteam init [DIRECTORY] [flags]
----

== Options

----
      --enable-wmdp           do not warn about WMDP; the customer intends to include it
      --force                 replace files that are already there
      --from string           a scaffold archive on disk, instead of downloading one
  -h, --help                  help for init
      --package string        the Java package to write red-team sources under (defaults to <groupId>.redteam)
      --source string         where to download the scaffold from
      --with-corpora string   remind the customer to pull this dated corpora artifact after init
----
