= akka organizations roles delete

Delete a custom role of the organization.

== Synopsis

Delete a custom role of the organization.
It is an error to delete a role that is still bound to principals, or that outstanding invitations are for, unless --cascade-role-bindings is specified, in which case those role bindings are deleted and invitations cancelled too.

[source,shell]
----
akka organizations roles delete ROLE_ID [flags]
----

== Options

[source,text]
----
      --cascade-role-bindings   Also delete the role bindings to the role, and cancel invitations for it.
  -h, --help                    help for delete
      --organization string     name or ID for organization
----
