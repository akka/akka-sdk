= akka optimize training evaluations wait

Wait for an evaluation to finish

== Synopsis

Stream status updates for an evaluation until it reaches a terminal phase.

----
akka optimize training evaluations wait EVALUATION [flags]
----

== Examples

----
  # Wait for an evaluation to complete
  akka-optimize training evaluations wait 9c2e4b7a1d63f085

  # Wait and exit with non-zero status if the evaluation fails
  akka-optimize training evaluations wait 9c2e4b7a1d63f085 --exit-status
----

== Options

----
      --exit-status   Exit with a non-zero status if execution fails or is cancelled
  -h, --help          help for wait
  -q, --quiet         Suppress progress output until evaluation completes
----
