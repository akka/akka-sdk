= akka optimize training evaluations annotate

Update the description for an evaluation

== Synopsis

Set or update the description for an evaluation.

The description is informational and does not alter the evaluation ID or results.

[source,shell]
----
akka optimize training evaluations annotate EVALUATION [flags]
----

== Examples

[source,shell]
----
  # Add a description to an evaluation
  akka optimize training evaluations annotate 9c2e4b7a1d63f085 \
    --description "March baseline"
----

== Options

[source,text]
----
      --description string   Description for the resource. Pass an empty string to clear
  -h, --help                 help for annotate
----
