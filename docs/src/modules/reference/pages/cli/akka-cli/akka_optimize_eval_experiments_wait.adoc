= akka optimize eval experiments wait

Wait for an experiment to finish

== Synopsis

Follow an experiment until it reaches a terminal status, showing each change as it happens.

Exits 0 on reaching COMPLETED, STOPPED, CANCELLED, or REFUSED.
Add --exit-status to exit non-zero when the run did not complete, or completed but the gate it was held to did not hold -- the same reasoning training runs wait applies to a smoke check's finding: an experiment that ran and answered no is not the same as one that never ran.

--timeout bounds the wait, not the run: on timing out this exits non-zero and the run carries on.

Under -o json, every change is written to stdout as one line of JSON -- status, the offset and item count, ending in one line with "terminal": true carrying the gate outcome and reason.
That stream, not this command's text, is the contract a script should read.

The experiment's whole record follows the terminal line once it is done, formatted like any other command's -o json output -- pretty-printed and not one line.
Use -o json-compact, or read it with "jq -c .", if a script reads this command's stdout line by line.

----
akka optimize eval experiments wait EXPERIMENT [flags]
----

== Examples

----
  akka-optimize eval experiments wait exp-ed745d2f
  akka-optimize eval experiments wait exp-ed745d2f --timeout 30m --exit-status
  akka-optimize eval experiments wait exp-ed745d2f -o json | jq -c .
----

== Options

----
      --exit-status        exit non-zero if it does not complete, or completes with a gate that did not hold
  -h, --help               help for wait
      --timeout duration   give up waiting after this long; unset waits indefinitely
----
