= akka optimize training snapshots download

Write one file of a snapshot to a file or standard output

== Synopsis

Write one file a snapshot's artifact holds to a file or standard output.

PATH is a file the artifact's manifest declares, as "training snapshots get" lists it under "files".
--kind names the artifact, since both kinds can hold a file of the same name.
SNAPSHOT may be a complete snapshot ID or an unambiguous prefix.

A file written with --file appears once the whole file has arrived, and replaces a file already there.
It is readable only by you, since it holds trained weights or optimizer state.

[source,shell]
----
akka optimize training snapshots download SNAPSHOT PATH [flags]
----

== Examples

[source,shell]
----
  # Write one rank's model file of a verl checkpoint to rank1.pt
  akka optimize training snapshots download 3f2a9c71bd04 actor/model_world_size_4_rank_1.pt \
    --kind trainingState --file rank1.pt
----

== Options

[source,text]
----
  -f, --file string   Output file. '-' writes the file to stdout (default "-")
  -h, --help          help for download
      --kind string   Artifact kind to read, either weights or trainingState
----
