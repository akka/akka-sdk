= akka optimize training base-models envelopes

List the deployment's measured training envelopes

== Synopsis

List the training envelopes the catalog measured on this deployment, and whether the catalog is advisory or strict.

An envelope is one device profile and GPU count with the methods, precisions and engines measured there, the largest model and active parameter count, the longest sequence and the most tokens one pass carries.
An advisory catalog admits a run outside every envelope with a warning that it may run out of device memory.
A strict catalog refuses it.

Run "training base-models get" to see the envelopes of one model.

[source,shell]
----
akka optimize training base-models envelopes [flags]
----

== Examples

[source,shell]
----
  # Every measured envelope, and the catalog's mode
  akka optimize training base-models envelopes

  # The device profiles measured for 8 GPUs
  akka optimize training base-models envelopes --jq '.measurements[] | select(.gpus==8) | .deviceProfile'
----
