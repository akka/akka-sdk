= akka specify fixtures freeze

Make a set immutable and record its content hash.

== Synopsis

Checks that no stored file still holds a secret the redaction should have replaced, then marks the set frozen with a hash of all its fixture files and the date.
A frozen set accepts no further recording, and a later replay refuses a set whose files no longer match the hash.

[source,shell]
----
akka specify fixtures freeze <set> [flags]
----

== Options

[source,text]
