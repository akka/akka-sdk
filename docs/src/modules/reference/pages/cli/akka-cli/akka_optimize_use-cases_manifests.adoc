= akka optimize use-cases manifests

Frozen use-case sets, and which one is routing

== Synopsis

A manifest is the closed set of use-case routing rules produced by a freeze.

Its identity is a content hash over the use-cases, their labels, their centres, their backends and the threshold, so a freeze that produced nothing new produces no new manifest.
Everything in it is immutable;
being live is a property of the gateway.
