= akka optimize training base-models get

Display one allowed base model, its selection status, and its measurements

== Synopsis

Display admission and selection status for an allowed entry, and the training measurements for it.

BASE_MODEL takes the repository, the entry ID or an unambiguous prefix of it, or the registry version a selection registered, such as qwen/qwen3-8b:v1.

STATUS is admission: PENDING while the repository is being read, AVAILABLE once it can be used, and UNSUPPORTED, UNAVAILABLE or WITHDRAWN where it cannot.
SELECTION is PREPARING, FETCHING or READY, and is absent where nobody has selected it.

"Measured training envelopes" lists measured methods, precisions, device counts and sequence lengths.
Advisory catalogs admit runs outside these measurements with a warning that the run may run out of device memory.
Strict catalogs require a measured envelope.
Use "training base-models envelopes" to see every measured envelope and the catalog's mode.

GPU MEMORY PER GPU is the memory of each GPU.
HOST MEMORY PER NODE is the memory of the node that holds those GPUs.
Host memory stays a hard limit.

"Completed on this deployment" lists what has run over the model on this deployment, at any revision.
It shows one run for each method, precision, engine, device profile, and training and rollout device count that completed.
That run is the one at the longest sequence length.
TRAINING PEAK is the most device memory the training pass held.
HOST MEMORY is the busiest node's peak.
TOKENS/S PER DEVICE is the tokens the run's steps processed over the device time they took.
The table is taken from the 500 newest completed runs over the model.

"Ran out of memory" lists the 20 newest runs that ran out of memory, and which memory.
A dash is a figure the run did not measure.
These runs never refuse or admit a run.
Read one with "training runs get".

With -o wide, both tables add each run's REVISION.
The completed table adds DEVICE PEAK, the most memory any device had in use.
HOST MEMORY adds what the run could have added on that node.

[source,shell]
----
akka optimize training base-models get BASE_MODEL [flags]
----

== Examples

[source,shell]
----
  # Display an entry
  akka optimize training base-models get Qwen/Qwen3-8B

  # Or by the registry version a run names
  akka optimize training base-models get qwen/qwen3-8b:v1
----
