= akka optimize training curations wait

Wait for a curation to finish

== Synopsis

Follows a curation to a terminal phase and prints what it produced.

Interrupting with Ctrl-C stops watching.
The curation carries on, and wait picks it up again.
--timeout bounds the wait, not the curation: on timing out this exits non-zero and the curation carries on.

----
akka optimize training curations wait CURATION [flags]
----

== Examples

----
  akka-optimize training curations wait curation-7d496e82
  akka-optimize training curations wait curation-7d496e82 --timeout 2h --exit-status
----

== Options

----
      --exit-status        exit non-zero unless it completed
  -h, --help               help for wait
      --timeout duration   give up watching after this long; the curation carries on
----
