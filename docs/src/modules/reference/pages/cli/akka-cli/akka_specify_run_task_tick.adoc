= akka specify run task tick

Tick the task claimed by this agent and record its completion.

== Synopsis

[Incubating] Records the action under the idea's lock and prints JSON.
--run names an open Implement or Converge run;
--task is a T-id and --agent is agent-+++<positive number="">+++.
A console command may touch only its own run.
Held, handed-over and already claimed tasks are refused.
Raise takes single-line question and option text without table separators.+++</positive>+++

[source,shell]
----
akka specify run task tick [flags]
----

== Options

[source,text]
----
      --agent string   agent id, such as agent-1
      --dir string     project directory (default: current)
  -h, --help           help for tick
      --json           print JSON (task actions always print JSON)
      --run string     open run id (default: AKKA_RUN_ID)
      --task string    task id, such as T001
----
