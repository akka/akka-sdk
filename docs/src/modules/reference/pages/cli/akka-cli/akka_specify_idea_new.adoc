= akka specify idea new

Start an idea from its first sentence.

== Synopsis

[Incubating] Start an idea.
Its id is the title's slug, or the words' when there is no title.
The lane is how it ships: akka (Deploy to Akka) or internal (Commit to internal systems).

Examples:   akka specify idea new --lane internal --limit 50 Lend to small businesses as well as to people

[source,shell]
----
akka specify idea new WORDS... [flags]
----

== Options

[source,text]
----
      --dir string           project directory (default: current)
  -h, --help                 help for new
      --json                 print idea.json
      --lane string          the shipping lane: akka or internal
      --limit string         the spending limit in US dollars
      --new-project string   start a new project of this name instead of extending this one
      --spec string          the spec the idea continues
      --title string         the idea's title (default: its words)
      --topic string         the discovery topic the idea starts from: its folder name, code or id
----
