= akka optimize training runs cancel

Cancel an active training run

== Synopsis

Cancel an active training run and release its allocated compute resources.

The command returns immediately after the cancellation request is accepted.
Use "training runs wait" to monitor the run until it reaches the CANCELLED phase.

----
akka optimize training runs cancel RUN [flags]
----

== Examples

----
  # Cancel a training run with confirmation prompt
  akka-optimize training runs cancel 7d496e82c3a15f04

  # Cancel a training run without confirmation prompt
  akka-optimize training runs cancel 7d496e82c3a15f04 --force
----
