= akka optimize training pipelines

Manage training pipelines

== Synopsis

A training pipeline executes a sequence of curate, train, and evaluate stages.

Downstream stages can reference outputs from upstream stages using the syntax "@stageName" in place of a dataset hash or model ID.
Stages can also define a minimum required mean score to gate subsequent execution.

Each stage executes as an individual training run linked to the pipeline ID.
If a pipeline stops before completion, you can restart it using "training pipelines resume".

== Examples

----
  # Submit a pipeline and wait for completion
  akka-optimize training pipelines start -f pipeline.json --wait

  # List active and incomplete pipelines
  akka-optimize training pipelines list --phase open

  # Display stage-by-stage status for a pipeline
  akka-optimize training pipelines get 3f9a21c4d08b7e56
----
