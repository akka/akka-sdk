= akka optimize routing-lock

Lock routing changes for the whole gateway, with a reason

== Synopsis

While routing is locked, the gateway refuses every write that changes where traffic goes, whoever sends it, experiment actions included.
Reads, rule tests, ingest and writes that change no traffic still work.
The lock records who set it, when and why.

Setting and lifting the lock move no traffic, so neither asks first.
