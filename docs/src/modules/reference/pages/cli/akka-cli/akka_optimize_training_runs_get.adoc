= akka optimize training runs get

Display details for a training run

== Synopsis

Display a training run: its state, what it produced, and what it cost.

"State" says where the run is: its phase, how far it has got, the step it last saved and why it failed.
"Results" is the model it registered, its losses and its start checks.
"Cost" is its device time, its duration and the memory its devices held.

--settings, or -o wide, adds the settings the run was started with: its configuration, hyperparameters, engine settings, runtime and run settings.
-o json is the whole run.

A supervised run on more than one device checks its own numerics before its first update.
"Start checks" says whether they passed, and --checks shows each check: what it measured, its bound, and the engine setting that sets the bound.

To monitor status changes in real time, use "training runs wait".

[source,shell]
----
akka optimize training runs get RUN [flags]
----

== Examples

[source,shell]
----
  # Display run details
  akka optimize training runs get 7d496e82c3a15f04

  # Show each start check against its bound
  akka optimize training runs get 7d496e82c3a15f04 --checks

  # Show the settings the run was started with
  akka optimize training runs get 7d496e82c3a15f04 --settings

  # Extract the registered model version using jq
  akka optimize training runs get 7d496e82c3a15f04 --jq .modelId
----

== Options

[source,text]
----
      --checks     Show each start check: its verdict, each value against its bound, and the setting behind it
  -h, --help       help for get
      --settings   Show the settings the run was started with, as -o wide does
----
