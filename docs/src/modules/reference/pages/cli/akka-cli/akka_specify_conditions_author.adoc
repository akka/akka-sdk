= akka specify conditions author

Write derived conditions into the project.

== Synopsis

Writes conditions into the project's generated set.
A condition whose id is already there is replaced, so re-running discovery updates its own work rather than accumulating duplicates.

An auditor a tool wrote does not run until its exact command is approved.
Pass --consent-for to approve the commands as they are written, naming the system being ported.
Give that only when you accepted the run at its outset: it is the consent that lets an unattended run proceed without stopping at each condition.

----
akka specify conditions author [flags]
----

== Examples

----
  akka specify conditions author --file conditions.yaml
  akka specify conditions author --file conditions.yaml --consent-for redash
----

== Options

----
      --consent-for string   approve the auditors as written, naming the system this run is porting
      --dir string           project directory (default: current)
      --file string          a YAML or JSON file of conditions, or - for standard input (default "-")
  -h, --help                 help for author
----
