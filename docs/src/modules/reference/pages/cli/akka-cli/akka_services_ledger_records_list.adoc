= akka services ledger records list

List the ledger records of a service, newest first.

== Synopsis

The `akka services ledger records list` command lists the ledger records of a service, newest first.

Pass one filter: `--type` for all records of one type, `--type` with `--component` for the records of one type produced by one component, `--evaluation` for every record produced during one evaluation, `--subject` for the records about one record, such as the evaluations of an interaction, `--control` for the executions of one control, or `--interaction` for what happened in one interaction: the interaction, the tool calls, guardrail decisions and sanitizations written during it, and its evaluations.
An interaction listing reads the ledger from `--from` on, which defaults to one day ago;
pass the time of the interaction or earlier for an older one.

Narrow the listing with `--outcome`, `--enforced` or `--report-only`, `--session` and `--flow`.
These are checked on each record the filter yields, so a narrowed listing costs the records it visits, not the records it returns.
The runtime bounds the records one page visits, so a narrowed page can hold fewer records than the page size, and the command follows empty pages until one holds a record.
Pass `--from` to bound the records a narrowed listing visits.
`--outcome` and `--enforced` or `--report-only` are rejected on a filter whose records cannot carry them, such as an outcome on interactions or an enforcement on evaluations.

`--from` and `--to` bound the record timestamp.
Each accepts an RFC3339 timestamp, a duration before now such as 24h, or now.

[source,shell]
----
akka services ledger records list SERVICE_NAME [flags]
----

== Options

[source,text]
----
      --component string     Component id of the producer. Requires --type.
      --control string       Control id. Lists the evaluations, guardrail decisions and sanitizations of that control.
      --enforced             Only guardrail decisions of an enforcing guardrail. Includes a fail of a fail-open guardrail.
      --evaluation string    Evaluation id. Lists every record produced during that evaluation.
      --flow string          Only records of this flow.
      --from string          Inclusive lower bound on the record timestamp (RFC3339 timestamp, duration ago, or 'now').
  -h, --help                 help for list
      --interaction string   Interaction id. Lists the interaction, the records written during it and its evaluations. --from defaults to 24h.
      --outcome string       Only records with this outcome, one of: passed, not-passed, inconclusive, allow, deny, error.
      --owner string         the owner of the project to use, needed if you have two projects with the same name from different owners
      --page-size int        The size of pages to fetch. Default and max is 100.
      --project string       project to use if not using the default configured project
      --region string        region to use if project has more than one region
      --report-only          Only guardrail decisions of a report-only guardrail.
      --session string       Only records of this session.
      --subject string       Record id. Lists the records about that record, such as the evaluations of an interaction.
      --to string            Exclusive upper bound on the record timestamp (RFC3339 timestamp, duration ago, or 'now').
      --type string          Record type, one of: interaction, activity, tool-call, evaluation, classification, control-configuration, guardrail-decision, sanitization.
----
