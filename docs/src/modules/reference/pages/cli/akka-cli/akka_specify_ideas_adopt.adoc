= akka specify ideas adopt

Write an idea and receipts reconstructed from git for each topic and spec no idea claims.

== Synopsis

[Incubating] Today's discovery topics and specs show as ideas derived from them.
Adopting writes each one's idea.json under .akka/record/, with a receipt for every station its timeline reached, marked reconstructed.
Adopted ideas have no lane and no limit until they are set.
Adopting again adopts nothing new.
--idea adopts only the derived idea with that id, the spec's or the topic's, and answers that it is already recorded when an idea claims it.

[source,shell]
----
akka specify ideas adopt [flags]
----

== Options

[source,text]
----
      --dir string    project directory (default: current)
  -h, --help          help for adopt
      --idea string   adopt only this derived idea: a spec's id (002-notices) or a topic's (T-006)
----
