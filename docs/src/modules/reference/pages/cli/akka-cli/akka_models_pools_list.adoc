= akka models pools list

List the accelerator pools available to the organization.

== Synopsis

Every inference-capable region declares pools of accelerator devices, and a project's accelerator allocation draws devices from one pool by naming it.

A pool name is a regional identifier and nothing more: two regions may name the same hardware differently, and one name may mean different hardware in different regions.
PRODUCT and MIG PROFILE say what the hardware actually is, so compare those - never the name - across regions.

The listing is discovery: how many devices a project may draw is decided by the region when the allocation is admitted, not here.

----
akka models pools list [flags]
----

== Examples

----
akka models pools list
akka models pools list --region aws-us-east-2 --organization acme
----

== Options

----

      --region strings        Only pools of this region; repeatable. Every accessible region when omitted.
