= akka optimize trained-models list

List trained and registered models

== Synopsis

List registered models, baselines, and provenance information.

Filter results using one of the following flags:   --workload: List models associated with a specific workload.
--base-model: List a base model repository and all models trained from it.
--base-model-id: List models trained from a specific base model entry ID.

----
akka optimize trained-models list [flags]
----

== Examples

----
  # List all models
  akka-optimize trained-models list

  # List models for a workload
  akka-optimize trained-models list --workload router

  # List models derived from a base model repository
  akka-optimize trained-models list --base-model Qwen/Qwen3-0.6B

  # List models derived from a base model entry ID
  akka-optimize trained-models list --base-model-id fbadb4b04a87c281

  # Output selected fields as JSON
  akka-optimize trained-models list --json modelId,baseModel,runId

  # Filter reinforcement learning models using jq
  akka-optimize trained-models list \
    --jq '.models[] | select(.method == "GRPO") | .modelId'
----

== Options

----
      --base-model string      Filter models by base model repository name
      --base-model-id string   Filter models by base model entry ID
  -h, --help                   help for list
      --workload string        Filter models by workload name or ID
----
