= akka optimize captures download

Save captures from the capture refinery into a directory

== Synopsis

Save captures from the capture refinery into a directory, by exchange id or by period.

Each is written to DIR/EXCHANGE_ID.json, the normalized record, or with --raw to DIR/EXCHANGE_ID.acp.gz, the raw capture as the gateway stored it, byte for byte.
--raw is not capture-reader's --with-raw, which adds the body bytes to a normalized record.

A period is by ship time, when the gateway sealed the capture: --from inclusive, --to exclusive.
It lists the captures the refinery has derived a record from, so a raw capture it has not derived yet is not in it.
By exchange id alone, a capture is found when it shipped in the hour the exchange started or the hour after.
Download a capture that shipped later by its period.

A file is written whole or not at all, and only you can read it.
A file already present is kept and not asked for again, so the same command run again finishes an interrupted download.
A capture the refinery does not hold is reported as missing, the rest are still downloaded, and the command then exits non-zero.

captures list and captures show read what this writes.

[source,shell]
----
akka optimize captures download (EXCHANGE_ID... | --from INSTANT --to INSTANT) [flags]
----

== Examples

[source,shell]
----
  akka optimize captures download 01M3Q7SVZNGDBC8QQW88PXWVX5 --dir captures
  akka optimize captures download --raw --dir captures \
      --from 2026-09-29T18:00:00Z --to 2026-09-29T19:00:00Z
----

== Options

[source,text]
----
      --dir string    the directory to write to, created when missing (default ".")
      --from string   start of the period, an ISO-8601 instant in UTC, inclusive
  -h, --help          help for download
      --raw           download the raw captures instead of the normalized records
      --to string     end of the period, an ISO-8601 instant in UTC, exclusive
----
