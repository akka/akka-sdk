= akka specify probes approve

Record that a declared probe's command may run.

== Synopsis

Records approval of a declared probe's exact command.
Approval is tied to the command as written: change it, and the probe waits for approval again.

Read the command before approving it.
It runs with your privileges, against your project, whenever a discovery selects that probe.

----
akka specify probes approve <probe> [flags]
----
