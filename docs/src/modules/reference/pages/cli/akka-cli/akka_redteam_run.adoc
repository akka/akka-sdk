= akka redteam run

Run the local red-team campaigns.

== Synopsis

Wraps the Maven invocation that runs every campaign under `src/redteam/`.

----
akka redteam run [flags]
----

== Options

----
      --goals string   the Maven goal to run under the redteam profile (default "verify")
  -h, --help           help for run
----
