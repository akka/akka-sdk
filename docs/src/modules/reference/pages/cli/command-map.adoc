The xref:reference:cli/akka-cli/akka.adoc[akka] page lists the flags every command accepts and every command group. Each group has a reference page that lists its commands and flags. This map names the group, what it acts on, and where its tasks are described. For the flags and behavior that the groups share, see xref:reference:cli/conventions.adoc[].

== Inference commands

These commands serve models and decide which model serves a request. They are an add-on to Akka Automated Operations.

[cols="2,4,3", options="header"]
|===
| Command group
| Acts on
| Tasks are in

| xref:reference:cli/models.adoc[`akka models`]
| Accelerator pools and allocations, models, the endpoints that serve them, and their API keys.
| xref:inference:serving/index.adoc[]

| xref:reference:cli/routing.adoc[`akka optimize rulesets`, `routing-classifiers`, `use-cases`, and `routing-policies`]
| The rules and policies that choose which provider serves a request.
| xref:inference:routing/index.adoc[]

| xref:reference:cli/cost-and-traffic.adoc[`akka optimize spend`, `callers`, `incidents`, `pricing-catalog`, and `captures`]
| What an organization spends on inference, and the traffic behind it.
| Reference only
|===

| Acts on
