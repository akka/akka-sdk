= Exit condition catalog

An extensive, browsable catalog of candidate exit conditions to consider for a project, organized by xref:sdk:enforced-mode.adoc#dod-types[Definition-of-Done type] and by project flavor. The shipped xref:reference:exit-conditions/default-library.adoc[default library] is deliberately small -- this catalog is for inspiration. Browse it, and adopt the conditions that fit your project.

Each entry names a candidate condition, when it applies, how it would be checked, and a source standard.
